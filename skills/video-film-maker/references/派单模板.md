# 派单模板（给 Boss 用）

这一份是给主对话（Boss）看的：怎样把一部片子交给 DSH 做，自己只花定方向、看稿、验收这三处的力气。

**要派的是品牌片、产品片、发布片、宣传片**：派法不一样（Boss 要定主陈述、确认风格帧，设计判断不够时要升级），剪辑单、审片单和验收办法在 [产品片/派单](产品片/派单.md)。下面的班底、文件边界、审片意见怎么转，仍然适用。

## Boss 自己做的事（不下放）

- 和用户定选题、方向、要不要短版；按 `video-growth-research` 定标题、封面方向、发布时间（调研本身也可以派 DSH）。
- 写创作简报 `docs\grill\<作品>\创作简报.md`：用户原话、这期给谁看、要兑现什么、必须说和不能说的、事实材料在哪。简报不用长，材料路径要全。
- 读稿（稿子节点交回的全文，一两千字）。稿子是最值得亲自看的地方：开场有没有讲清、事实对不对、有没有踩规矩。
- 最终验收（见文末「Boss 验收」），把试听片段交给用户听。
- 成品 README、`发布.json`、`docs\索引.md` 和现状页，以及发布。

## 班底

| 角色 | 谁 | 说明 |
|---|---|---|
| 剪辑师 | DSH，`lifetime: "persistent"` | 写稿、做画面、跑流水线、自审。一部片子一位，要来回改所以用持久会话 |
| 审片员 | DSH，另开一位，`lifetime: "once"` | 没参与制作，用同一份清单逐帧再看一遍。每轮审片新开一位 |
| 画师 | Codex，`target: "codex-desktop"`，`persistent` | 角色、插画、封面。由剪辑师或 Boss 派，写法见 [素材.md](素材.md) |
| 场景师（可选） | DSH，多位 | 片子长、想快：稿子和配音定了之后，按章节把场景分给几位同时写，每位只碰自己的场景文件 |

模型和强度照团队配置（work-workflow 的 `团队配置.md`）；表里没有剪辑师这一行时用 DSH 默认模型。

下面几张单子里的 `<片场>`、`<工作区>`、`<skill 目录>`、`<群号>` 是占位，**派单时换成本机的真值再发**（本机的值记在工作区自己的现状文档里），不要把占位原样发给助手。

## 一、剪辑单（开一部新片）

```
角色：剪辑师。加载 skill `video-film-maker`，照它做完一部片子。skill 入口：<skill 目录>\SKILL.md（先完整读 SKILL.md，再按它指的顺序读参考文档）。

位置：片场 <片场>；工作区 <工作区>（skill 里写 <片场>、<工作区> 的地方都按这两个读）
作品名：<作品名>（工程建在 <工作区>\work\<作品名>\，成品放 <工作区>\成品\<作品名>\）
片名（暂定）：<片名>
类型：<教程 / 介绍 / 对比测评 / 整活>
要不要竖屏短版：<要 / 不要>
接不接通用片头片尾：<接 / 不接>

这期讲什么、给谁看：
<两三句。观众是谁、卡在哪、看完能做到什么>

必须讲到的：
- <要点 1>
- <要点 2>
必须原样用的话（署名、致谢、片尾制作说明等）：
- 片尾群号：<群号>
- <原文>
不能讲的、要小心的：
- <例：不教换区；节点的讲法照频道规矩>

事实材料（稿子里的事实只从这些来，查不到的不写）：
- 创作简报：<工作区>\docs\grill\<作品>\创作简报.md
- <源码 / 文档 / 截图 / 原片 / 数据的路径，各自是什么>

素材：
- 角色和插画：<你自己派 Codex 画师（模型 <…>、强度 <…>）/ 列清单交我来派 / 用这些现成的：路径>
- <借用的社区角色及参考图路径；设定图画好先报我确认>

文件边界：你只写 <工作区>\work\<作品名>\ 和成品目录里的成片、字幕；docs\、成品 README、发布.json、别的作品目录都不要动。片场 <片场> 只读（发现片场的问题写进报告，不自己改）。

回传节点（用 report_parent，除最后一次外 final=false，交完不用等我回复，继续往下做；我有意见会补充给你）：
1. 稿子定稿：交稿子全文（去掉标记的可读版）、章节和预计时长、事实表里「未验证」的条目、要画的图清单。
2. 全片画面自审完、整片渲染之前：交审片记录路径、你给自己打的分和最差三处、最能代表全片的 8 张帧的路径。此时我会派审片员，审片意见会转给你，改完再渲。
3. 成片：按 skill 的交付报告格式（final=true）。

只在这几种情况用 ask_parent 停下来问：材料互相矛盾或关键事实查不到；要动文件边界以外的东西；借用角色的设定图需要确认。其余工程上的取舍自己定，写进报告。
```

## 二、审片单（剪辑师交了第 2 个节点之后）

```
角色：审片员。你没有参与这部片子的制作，任务是用观众和质检的眼光把它逐帧看一遍，只看只记，不改任何文件。

加载 skill `video-film-maker`（入口 <skill 目录>\SKILL.md），读其中的 references\验收.md 和 references\频道规矩.md，照「画面审片怎么做」和「独立审片」两节执行。

位置：片场 <片场>；工作区 <工作区>
工程：<工作区>\work\<作品名>\
要看的帧：review\<轮次>_zh\ 下全部 PNG（有短版时还有 review\<轮次>_short\），对照同目录的 index.md（每张图对应的秒数、句子、标记、字幕）。每一张都用看图工具打开原图看，不许跳、不许只看一部分。
稿子：film\src\script.json。每一刻画面上该出现什么，看工程里 制作记录.md 的分镜表。派单要点：<把剪辑单里「这期讲什么」「必须讲到的」「不能讲的」「必须原样用的话」抄过来，审片员要拿它核内容>。简报：<创作简报路径>。
先看几张合格的范例帧找标准：<片场>\template\review\final_zh\（另可加一部本频道已发片子的 review\final_zh\）

交回：把审片意见写到 <工作区>\work\<作品名>\review\<轮次>_zh\独立审片.md（只写这一个文件）：
1. 问题清单：帧文件名｜问题｜属于清单哪一类｜建议怎么改｜严重程度（必须改＝会误导操作、内容或署名有错、一眼能看出破版；建议改＝只影响好看）。原因是你推测的要写明是推测。
2. 稿子上的问题：开场 20 秒讲没讲清这期是什么；有没有踩频道规矩的句子（写出句 id 和原文）；有没有和画面对不上的地方。
3. 从观众角度：哪一段最想划走、全片最差的三处、总体打分（十分制）。
4. 你一共看了多少张、有没有打不开的。
用 report_parent(final=true) 交 300 字以内的摘要：必须改的有几条、最严重的三条是什么、文件路径。
```

审片意见转给剪辑师：`futureaide_send_agent` 发一句「审片意见在 <路径>，逐条处理：改了的写怎么改的，不改的写理由；改完重抽受影响的帧复查，然后渲染出片」。必须改的条数多（十条以上）时，改完再派一位新的审片员看第二轮。

## 三、改片单（在已有的片子上改）

```
角色：剪辑师。加载 skill `video-film-maker`，照其中 references\改片与短版.md 的「改片」做。

位置：片场 <片场>；工作区 <工作区>
工程：<工作区>\work\<作品名>\（先读它的 制作记录.md、稿子和要改的场景，看几张原片的帧）
现在的成片：<路径>（不要覆盖；新版本成片名用 <…_v2_1080p60.mp4>）

要改的（用户原话）：「<原话>」
具体改法：
- <改动 1：改哪一段、改成什么、依据是什么>
- <改动 2>
保持不动的：<例：其余章节的讲法、已确认的开场>

事实材料：<新增内容的出处路径>
文件边界、回传节点、提问条件同剪辑单；节点 1 改成「改稿后的新旧对照（改了哪几句）」。
```

## 四、场景师单（可选，稿子和配音定了之后并行写场景）

```
角色：场景师。加载 skill `video-film-maker`，读 references\画面.md、references\验收.md 和片场的积木手册。

位置：片场 <片场>；工作区 <工作区>
工程：<工作区>\work\<作品名>\。稿子 film\src\script.json 和时间表已经定了，不要改它们。
你负责的章节：<章节 id>，只写 film\src\scenes\<文件名>.tsx 这一个文件（场景登记由剪辑师统一做）。
这一章要表现的：<逐句的画面意图，或写「见 制作记录.md 的分镜表」>
可用素材：<图的路径>
写完自己抽帧审片：.\film.cmd review zh --round <你的名字> --only <章节 id>，逐张看，审片记录写在那一轮目录里。
交回（report_parent final=true）：场景文件路径、用了哪些积木、审片记录路径、未解决的问题。
```

## Boss 验收（成片交回之后）

按这个顺序，力气花在刀刃上：

1. **读交付报告**，先看「未验证」和「自己定的取舍」两段。
2. **稿子**在节点 1 已经读过；改过的句子再看一眼。
3. **看帧**（原尺寸，十张左右）：第一帧和前 20 秒里的两三张（开场讲没讲清）、每章一张关键帧、审片员点名的最差三处改后的样子、片尾群号卡和署名、短版的第一帧和结尾。看的是：像不像本频道的片子、有没有一眼能看出的破版、事实和署名对不对。
4. **体检表** `review\check_zh.md` 全部通过。
5. **试听片段交给用户**：听感只有人能验。用户审片审听之后的意见，原话转给同一位剪辑师（持久会话还在），走改片流程。
6. 过关后写成品 README 和 `发布.json`，按 `video-growth-research` 排期上传。

抽查发现问题多（十张里三张以上有毛病），不要自己动手修，退回剪辑师并再派一轮审片：问题多说明自审没做实，要的是它把流程走完，不是 Boss 替它返工。
