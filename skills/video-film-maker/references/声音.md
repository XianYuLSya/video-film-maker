# 声音：配音、念法、配乐、音效

声音全部由片场命令生成，你要做的是三件事：把念法表配对、把配乐编排写好、让画面上的每一下都有对应的音效。字段的准确写法以片场 README 的 `film.json` 字段表为准。

## 配音

```
.\film.cmd voice zh
```

一句一段调微软神经语音（晓伊，语速 -3%），按句子文本缓存，改了哪句只重新合成哪句。跑完会打印句数、说话时长、全片时长、每章起止。配音需要联网，失败会自动重试；连续失败先确认网络，再重跑同一条命令（已合成的不会重来）。

**时间表是配音的副产品**：每句的起止、每个 `{标记}` 的时刻、字幕怎么切，都在这一步定下来。所以改了稿子必须重跑配音，之后才能抽帧和渲染。

## 念法表

晓伊会把没见过的缩写当单词念，把数字串念成一个大数。凡是稿子里的英文缩写、型号、版本号、数字串、带符号的名字，都要过一遍念法：

| 稿子里写 | 念法表里写 |
|---|---|
| `DSH` | `D S H` |
| `TUN` | `T U N` |
| `2FA` | `二 F A` |
| `v2rayN` | `V two ray N` |
| `Node.js` | `Node J S` |
| `install.ps1` | `install 点 P S 1` |
| `24.14`（版本号） | `二十四点一四` |
| `123456789`（群号，画面上显示时） | `一二三，四五六，七八九` |
| `FutureAide` | `Future Aide` |

- 念法表在 `film.json` 的 `say` 里，一行一对：`["原文", "念法"]`。字幕仍然显示原文。
- `film.cmd lint` 会列出稿子里所有英文词、数字和符号串，标出哪些还不在念法表里。逐个判断：普通英文单词（Claude、Google Play）一般念得对，不用加；缩写、型号、混着数字的名字要加。
- 你听不到念得对不对。所以念法靠规则保证，并在交付报告里把所有念法替换和拿不准的词列出来，请人审听。
- 口播里不念群号（规矩见 [频道规矩.md](频道规矩.md)），群号只在画面和简介里。

## 配乐

配乐编排写在 `film.json` 的 `music` 里。

**最简单的写法**：一首曲子铺满全片，说话时自动压低，开头结尾淡入淡出。不确定怎么编排时就用这个，稳妥。

**分段写法**：按章节换曲，让情绪跟着内容走。常用的编排：

| 段落 | 用哪首 | 说明 |
|---|---|---|
| 开场钩子、收尾 | Cat Walk | 明快有劲，片名或点题那一下可以对在第 16 小节，收尾高潮对第 48 小节 |
| 讲解、原理 | Tonight | 松弛，适合听人讲话 |
| 操作演示、实战 | House Vibez | 有推进感 |

- 每段写从哪一章（或哪一句）开始、用哪首、从第几小节起；可以指定让某句某个标记落在第几小节上，这样片名砸出来的那一下正好踩在鼓点上。
- 内置三首的拍子是实测过的，对小节准。换别的曲子没测过拍子时，只能整首平铺，不能对小节。
- 章节名、句子 id 写错时，命令会报出是哪一段找不到什么，照着改。
- 短版一般整条一首 Cat Walk，从第 16 小节起（直接进高潮）。

## 音效

音效挂在画面动作上：东西弹出来、点击、打勾、翻页、盖章、镜头推拉。每个场景的 `sfx()` 返回这一章的音效清单，每条写「哪一刻、哪种音效、多大声」。

- 用积木时，每块积木有配套的音效函数，把它的结果展开进 `sfx()` 就行，时间自动和积木的动画对齐。光标点击同理（光标组件自带点击音效函数）。
- 自己加音效时，时刻从标记取（`C('c1','card') - 0.05` 这样），不手写秒数。
- 常用种类：`pop`（弹出）、`tap`（轻点）、`click`（点击）、`ok`／`confirm`（成功）、`swoosh`／`whoosh`（划入划出）、`page`／`slide`（纸张翻页滑动）、`stamp`（盖章）、`marker`（荧光笔）、`key`（敲键）、`lock`（锁定）、`zin`／`zout`（镜头推拉）、`sparkle`／`chime`（亮点）。全表在 `film\src\kit\sfx.tsx`。
- 音量 0.25–0.5。同一刻不要叠三个以上；一连串快速出现的东西用同一种轻音效（`tap`），别每个都用重的。
- 不是每个动作都要配音效。字幕切换、细小的淡入淡出不配。

## 混音和合成

```
.\film.cmd audio zh      # 配乐 → 音效清单 → 音效轨 → 混音
.\film.cmd mux zh        # 合成到成品目录，同时出 SRT
```

`audio` 结束时打印整体响度和真峰值，目标是 -14 LUFS、真峰值不高于 -1.5 dBTP，脚本会自动归一和限幅。画面的音效清单变了（加了元素、改了时刻）要重跑 `audio`；`status` 会提示。

## 交付时关于声音怎么说

你测得了的：响度、真峰值、时长、有没有解码错误、字幕和时间表是否一致。照实报数。

你测不了的：念得对不对、好不好听、配乐会不会盖住人声、音效响不响、音画合不合拍。写进「未验证」，并且：

```
.\film.cmd clip zh 0 36                # 切一段带画面的审看片段
.\film.cmd clip zh 282 368 --audio-only    # 只要声音
```

把开场、每个新做或改过的段落各切一段（每段不超过一分半），连同念法清单一起交上去。
