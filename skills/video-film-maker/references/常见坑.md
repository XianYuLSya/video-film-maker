# 常见坑

都是旧片里真实踩过的。遇到报错先来这里对一下；片场 README 的「常见报错」是另一份，两边都看。

## 做事顺序上的坑

| 现象 | 原因 | 怎么办 |
|---|---|---|
| 改了一句稿子，画面、字幕、配乐全对不上 | 稿子改了没重跑配音；或者只重跑了配音，没重跑声音和渲染 | 改稿后固定走：`lint` → `voice` → 抽帧 → `render` → `audio` → `mux` → `check`。不确定就 `film.cmd status` |
| 先写了画面，稿子后改，场景里的时间全错 | 顺序反了 | 永远是 稿子 → 配音 → 画面。场景里不写绝对秒数，只从句子和标记取时间 |
| 抽帧报「某句里没有标记 {xxx}」 | 稿子里删了或改了这个标记，场景还在用；或者两个条目 id 撞了（气泡和口播句同名） | 对一下稿子和场景；气泡 id 一律 q 开头，全片 id 不重复。`lint` 能提前查出来 |
| 整片渲完才发现错字或排版问题 | 没审片就渲了 | 整片渲染之前必须走完画面审片（[验收.md](验收.md)） |
| 开新片后配乐、念法、抠图名单还是上一部片的 | 从旧片拷的工程带着旧内容 | 用片场的 `new_film.py` 开片，不要从旧片拷工程；这些内容都在 `film.json` 里，开片时是空白的 |
| 成片名没改，新版本把旧成片盖了 | 合成默认写同一个文件名 | 改版先在 `film.json` 里改成片名（带 `_v2`）。片场的 `mux` 遇到同名文件会先把旧的改名备份，但别依赖它 |
| 画师的图迟迟不到，整片卡住 | 画图慢，派晚了 | 稿子定了立刻派画师，和写画面并行；图没到先用占位 |
| 画了一批姿势才发现角色形象不对 | 没先确认设定图 | 借用社区角色时先画设定图，报上级确认再批量画 |
| 角标写着「数据均为示例」，可画面里是真实数据 | 没分清这一段数据是真是假 | 角标只写「示意画面」。开工就定下来，别等渲完 |

## 渲染上的坑

| 现象 | 原因 | 怎么办 |
|---|---|---|
| 渲到一半浏览器崩溃、内存越涨越高 | 一口气渲太多帧 | 用 `film.cmd render`，它按 3000 帧一段分批、每段新起浏览器，失败自动降并发重试 |
| 渲染中断（会话结束、进程被杀） | 后台任务随会话结束 | 再跑一次同一条 `render` 命令，已完成的分段会跳过，坏的分段会被核出来重渲 |
| 改完重渲，结果还是旧画面 | 旧分段还在，被当成「已完成」跳过了 | `render` 支持按秒数范围重渲（`--from --to`）；改动范围大就清掉输出目录整片重渲 |
| 抽帧或渲染报找不到字体、图片（404） | 素材不在这部片子的 `film\public\` 里 | 公共素材由 `new_film.py` 拷好；自己加的图放 `film\public\art\`，路径照积木手册的写法 |
| 类型检查过了，渲染时才报错 | 缺必填属性、图片不存在这类问题只在运行时暴露 | 每写完一个场景就抽帧，不要攒到最后 |
| 两个镜头动作互相打架，画面被拉回全景 | 两个镜头关键帧的时间段重叠 | 一个时刻只留一个镜头目标，前一个推完后一个再开始 |

## 本机环境的坑

- **路径里有中文。** 命令里的路径一律加引号。PowerShell 5.1 读不带 BOM 的 `.ps1` 文件会把中文读坏，所以不要自己写 `.ps1` 脚本来跑流程；要写脚本就写 Python，用 `film-kit\.venv` 的 Python 跑。
- **PowerShell 里别用 `python -c "带方括号和引号的一长串"`**，会被解析坏。写成 `.py` 文件再跑。
- **中文输出乱码**（`ȫ��` 这种）：是控制台编码，数据没坏。片场命令已经处理了；自己跑 Python 时先设 `$env:PYTHONIOENCODING = 'utf-8'`。
- **建目录联接**用 PowerShell 的 `New-Item -ItemType Junction`，`cmd` 的 `mklink` 在中文路径下会失败。（新片的 `node_modules` 由 `new_film.py` 建好，一般不用自己动。）
- **`robocopy` 退出码 1 是成功**（表示有文件被复制），8 以上才是出错。
- **不要删文件。** 要清理的东西移到 `<工作区>\clean\<日期>-<事项>\`。C 盘空间紧，中间文件都放 D 盘的工程目录里。
- **本机时区是美东**，北京时间 = 本机时间 + 13 小时。文档里写日期和发布时间按北京时间。
- **网络**：配音要联网。如果当前会话带着代理环境变量导致某些国内站点连不上（握手报错），那是代理端口不放行，和片场无关；配音连不上时报告上级，不要自己改系统代理。
- **多个会话同时改同一个文档**（`docs\索引.md`、记忆文件）：改之前先重新读一遍最新内容，只改自己那一行。剪辑师一般不碰这些文件。
- **别的作品目录只读。** 想参考旧片的写法就去读，不要在里面跑命令、不要改。片场目录同理：发现片场的问题写进报告交上级。

## 内容上的坑

- **知识点删错比代码写错更贵。** 为了守某条规矩删内容之前，想清楚它拦的是什么。例：不教「换区」是对的，但「付款时网络出口要和账单地址在同一地区」是该教的，一起删掉就把观众带沟里了。
- **界面版本。** 同一个软件不同版本，按钮位置和行为都可能不一样。写稿前先确认讲的是哪个版本，界面文字以那个版本的源码或截图为准。
- **口播里说「你能搜到」「有多少人在用」这类话**，落稿前自己验一遍是不是真的。
- **编的例子**要么换成真实发生过的，要么让观众看得出是示例。旁白讲真实经历、画面放编的内容，会互相打架。
- **「填好了」不等于「做完了」。** 命令跑完要看产物在不在、对不对；报告里写的每一项完成，都要是你亲眼核过的。
