# 派产品片（给 Boss 用）

这一份给主对话（Boss）看：怎样把一条产品片交给 DeepSeek 做。通用的派法（班底、文件边界、回传、审片意见怎么转）照[派单模板](../派单模板.md)，这里只写产品片不一样的地方。

和教程片最大的不同：**教程片 Boss 主要看稿子，产品片 Boss 主要看风格帧。** DeepSeek 能把流程走完、把版面做对，但方向对不对它自己判断不了。被否的那一版，它自评 8.5 分（经过见[总纲](总纲.md)第三节）。

## 一、Boss 自己定的（不下放）

| 什么 | 为什么不下放 |
|---|---|
| 选题：做哪个产品、给谁看、发在哪、多长（骨架见[分镜](分镜.md)第三节） | 和用户定 |
| 事实来源：官网、当前版本的源码或安装包、徽标原图在哪；哪些信息不能露 | 剪辑师只从你给的材料里取事实 |
| **主陈述**：全片那一句话 | 第三版设计师的原话：挑哪一句当顶点，只能靠判断。派单里能定就定；定不了，让剪辑师出三条候选，你在风格帧节点挑 |
| **确认风格帧**，并拿给用户看 | 这类片子唯一可靠的方向验证是用户看一眼。两轮返工都是因为没先给他看 |
| 曲子的气质 | 剪辑师听不到声音，只能按数据选 |
| 最终验收，把成片交给用户 | |

第三版的设计师复盘时列过「必须留给有审美的人定的」六件事：选哪个界面状态当主角、全片那一句话、每场机位和构图的细调、亮场暗场的分配和整体闷不闷、功能怎么演成动作、最后看片拍板。上表的安排就是照这六件排的：前两件和最后一件归你；中间三件由剪辑师先做、你在风格帧上把关，不行就升级（第四节）。

## 二、产品片剪辑单

```
角色：剪辑师。加载 skill `video-film-maker`（入口：<skill 的 SKILL.md 路径>）。这是一条产品片，不走教程片的流程：读完 SKILL.md 之后，按 references\产品片\总纲.md 第十节的顺序把「产品片」目录下的文档全部读完，再读片场的 cine\手册.md，然后照总纲第四节的流程做。开工程用片场的 new_film.py 加 --kind product（总纲第四节有写），在起步工程上改。

作品名：<作品名>
类型：产品片（<品牌片 / 发布片 / 单功能发布>）
时长和骨架：<约 40 秒，骨架 A / 约 20 秒，骨架 B / …>
画幅：1920×1080 60 帧（镜头包目前只在横屏上做过；要竖屏先和我确认）
口播：无（整片没有口播是实测跑通的写法；要在结尾加一句口播的，先和我确认）
无配乐版：<要 / 不要>

产品和事实来源（文案只从官网原话取，界面只截这个版本）：
- 官网：<网址或首页源码路径>
- 产品当前版本的前端：<路径>（只读，拷副本到自己的工程里跑）
- 徽标和应用图标原图：<路径>
- 创作简报：<路径>

这条片子要证明什么（我的初步想法，你读完产品后可以提不同意见）：
<一两句>

主陈述：<「……」 / 未定，请出三条候选并标出你推荐的>
必须出现的能力：<…>
不能露的、不能说的：
- <例：带端口的页面不用；第三方软件名换成中性说法；不出现价格>
- 用词照频道规矩

配乐：<指定曲目 / 你按数据选，把曲名、拍长、进满的拍号和试听片段在风格帧节点一起交>

文件边界：同教程片的剪辑单（只写自己的工程目录和成品目录里的成片；产品仓库、片场、别的作品只读）。

回传节点：
A. 风格帧（用 ask_parent，**等我明确回复「通过」再做整片**）：按 产品片\风格帧.md 第三节的格式交：风格帧、变体、文案全文和主陈述候选、曲子和试听片段、自评、想请我定的事。
B. 全片自审完、整片渲染之前（report_parent，final=false，交完继续做）：审片记录、判例自检报告、数数表、最能代表全片的 8 张落定帧、手机宽度拼图。我会派审片员。
C. 成片（final=true）：SKILL.md 的交付报告格式，加 产品片\审片.md 第六节要求的几段。成片必须是画面最后一次改动之后重渲的，并且从成片文件里抽帧看过（审片.md 第五节）。

```

## 三、风格帧交上来之后怎么看

十分钟以内看完。**先别看它的自评分。**

1. **总览缩小了看。** 第一眼落在哪一张？应该是主陈述。遮住产品名：看得出是什么产品吗？
2. **和参照图并排**（`参照图\反例_全片连看.jpg`、`参照图\认可版_风格帧总览.jpg`、`参照图\正例_总览.jpg`）：它更像哪一边？
3. **手机宽度拼图和亮度的数。** 暗不暗（暗场镜头平均亮度低于 9 就是偏暗）？每格的主体认得出吗？大字读得出吗？
4. **每张原图**：这句话的证据在画面上吗？是画面里最清楚的地方吗？界面上有没有不该露的字？
5. **文案**：逐句对官网。有没有口号、有没有承诺。主陈述挑一条。
6. **变体**各挑一个。
7. 然后才看它的自评：它挑的「最弱两张」和你看到的一样吗？不一样，说明它没看出问题，批注要写得更具体。
8. **拿给用户看**：总览、主陈述那张原图、落款那张原图，加一句「主陈述是……」。用户的原话原样转给剪辑师。

回复只有两种：

- 「通过」。可以附带小修改（「通过，SF6 的字挪到右边」）。
- 退回。批注具体到哪一张、嫌什么、往哪个方向改：「SF3 主角太小，表单要占到半屏」比「SF3 不够有分量」有用。它猜着改容易改错对象。

**批注怎么写（2026-11-11 第一次试片的教训）**：

- 写清是哪一张、差在哪、照哪一张的标准改。「SF3 是这一轮最好的一张，其余照它做：主角至少占画面宽度三分之一」比「主角不够突出」管用得多，第二轮它就改对了。
- 批注别让它去和镜头包作对。我批过一句「别盖黑带」，它的做法是把压暗调淡，结果字压在灰纱上，比黑带更糟。要说的是用什么办法（换版式、挪机位），不是只说不要什么。
- 它在报告里列的「skill 与片场的问题」要当真看。这次它报的两条（左上版式的暗带盖不住第二行和副句、落款必须有图标）查实都是镜头包的毛病，改包比让它绕着做省事。
- 它的自评分不能当依据：第一轮自评 17 分，实际七张里六张主角读不出。看图，不看分。

## 四、升级：它的设计判断不够时

**什么时候升级**：风格帧退回两次还不过；剪辑师报告某项能力想不出怎么演；你看着觉得「没做错，但没劲」，又说不清怎么改。

**怎么升级**：不要把整条片子收回来交给更强的模型重做。只把最吃判断的那几件事交给它，做完还给剪辑师执行。更强的模型指团队里负责设计的那一位，按团队配置派。

```
角色：设计师。这是一条产品片，剪辑师（DeepSeek）已经做了产品简报、文案、分镜和 <几> 轮风格帧，卡在方向上。请你只做下面几件事，做完交回，由剪辑师继续执行。

先读：skill `video-film-maker` 的 references\产品片\总纲.md、审美判例.md、分镜.md 第四、五节；工程 <路径> 的 制作记录.md；风格帧 <路径>；我和用户的批注：<原话>。

要你定的：
1. 每个镜头的主角：哪一页、哪个状态、哪一块（可以推翻剪辑师的选择）。
2. 主陈述：<已定 / 请定一句>。
3. 每个镜头「动作演的是什么」，一个镜头一句，写到「谁在动、怎么动、演的是哪个动词」。
4. 在现有风格帧上批注：每张写「留 / 改（改什么）/ 重做（往哪个方向）」。<需要时：直接把开场和主陈述两张改到位，作为剪辑师的标准。>

不用你做：截图、运动实现、对拍、声音、审片。只写工程里的 设计批注.md <和你改的那两个镜头的文件>。
```

升级之后剪辑师重出风格帧，仍然要过你和用户。

第三版设计师的预判是：给了镜头包和机位预设，DeepSeek 能出「不出错」的风格帧，但「好看到能和海报放一起」那一档大概率做不到，难在两处：看不准自己的渲染图，想不出把功能演成动作的点子。**未验证：DeepSeek 照这份教材和镜头包实际做一条产品片的水平，还没有试过。** 范例片是做镜头包的人自己做的，它能证明工具和流程走得通，证明不了 DeepSeek 的判断够不够。第一次派的时候，按「大概率要升级一次」来排时间。

## 五、审片单（节点 B 之后）

在[派单模板](../派单模板.md)的审片单基础上改三处：

```
……读 references\验收.md、references\频道规矩.md，以及 references\产品片\ 下的 总纲.md、审美判例.md、审片.md，照 产品片\审片.md 第四节里「你是被派来当审片员的」那一段执行。

给你的材料：review\<轮次>_zh\ 下的帧和 index.md；连续抽帧的几段 <目录>；文案全文；制作记录里的「产品简报」和「分镜表」；通过的风格帧 <目录>。不要读制作记录里的自评和判例自检报告。

交回的 独立审片.md 里，在问题清单之前，先回答 产品片\审片.md 第四节的六道题，每道写理由和帧；并用 产品片\风格帧.md 的评分表给落定帧打分。
```

风格帧阶段也可以派一位审片员先筛一遍（用[风格帧](风格帧.md)的评审表，低于 14 分退回），省你的时间；但它过了不等于方向对，你和用户那一眼不能省。

## 六、Boss 验收（成片交回之后）

1. **读报告**，先看「未验证」「已知瑕疵」「有意不照判例做的地方」。
2. **确认成片是最新的画面**：报告里有没有「成片复看」那一段（从成片抽的全片连看）；自己从成片里抽两三帧，和它最后一轮审片的帧对一下。做范例片时出过「改了画面、渲染跳过了旧分段、体检全绿」的事。
3. **落定帧对风格帧**：每个镜头一张，和你通过的那版并排。
4. **手机宽度拼图和亮度**：从成片抽的那张。
5. **接缝连续帧**：挑两三个接缝看。有没有脏帧、主体被切开、半边黑。
6. **数数表**：冲击几处、亮场几场、每句大字停多久、落款静止多久、第一句大字在第几秒。
7. **判例自检报告**：五道判断题（主1、主2、画2、动1、拍1）它写的依据站得住吗？
8. **演示数据**：自己再扫一遍成片帧里读得出的界面文字。这一项出事是对外的事故。
9. **体检表**全过；成片回测的整体偏移在 1 帧以内。
10. **交给用户**：成片和试听片段。连续动态和听感只有人能验。用户的话原样转回同一位剪辑师。

抽查发现问题多，退回剪辑师并再派一轮审片，不要自己动手修（理由同[派单模板](../派单模板.md)）。方向上的问题（主角弱、话没证据、动作说不清）不是再审一轮能解决的，走第四节的升级。
