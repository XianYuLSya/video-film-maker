# 审片和验收：产品片多做的事

[验收](../验收.md)里的三道关（稿子体检、画面审片、成片体检）、原尺寸逐张看、记问题、改、复查、给自己打分，产品片全部照做。这一份只讲产品片**多出来**的部分：没有口播所以要自己点名取帧；运动、清晰度、亮度、拍子要专门查；渲完必须从成片里再看一遍；还要回答几道版面体检量不出来的判断题。

先记住两件事：

- **版面体检全绿、和风格帧一致，只说明没做错，不说明做得好。** 被否的那一版就是体检零错误、逐像素一致、自评 8.5 分交上去的。
- **体检全绿，也不说明成片就是你最后改的那个样子。** 见第五节。

## 一、取帧：自己点名

产品片没有口播，片场按口播取帧的规则取不到什么。垫片里会自动每 1 秒取一张，这只够看个大概。每一轮审片另外点名这三类：

| 取什么 | 怎么取 | 看什么 |
|---|---|---|
| 每个镜头的落定帧 | `.\film.cmd stills FilmZh <每个镜头落定的秒数…>`，或 `review … --at` | 和通过的风格帧并排比 |
| 每个主动作 | `review … --every 0.1 --from <动作开始> --to <动作结束后 0.5 秒>` | 运动连不连续 |
| 每个接缝 | `review … --every 0.07 --from <接缝前 0.4 秒> --to <接缝后 0.5 秒>` | 转场有没有脏帧 |

秒数从分镜表的拍号换算。把这张「取帧表」填进制作记录（产品片的制作记录模板里有这一节），每一轮照着取，不用每次重算。范例片的取帧表可以当样子看：八个落定帧、开场、一段卡片交换、六个接缝。

每一轮仍然是先 `probe` 再 `review`，用同一个 `--round`。转场进行中的那零点几秒不参加 `probe`（画面在飞，不算排版问题），所以接缝只能靠你看。连续抽帧一次会出几十张，一段一段取。

抽帧时命令行里打出的 `[注意] [镜头包] …` 每一条都要处理，对着手册「防呆清单」改。**这些提醒只在抽帧时打，整片渲染时不打**，所以别跳过抽帧直接渲。

## 二、工具

都在片场的 `tools\` 下，用片场的 Python 跑，命令的写法以手册「审片工具」一节为准：

| 要做的事 | 工具 |
|---|---|
| 一批帧拼成一张连着看（全片连看、一段连续抽帧） | `sheet.py grid` |
| 直接从**成片**抽帧拼图（成片体检；也可以只抽一个接缝） | `sheet.py video` |
| 按 100% 裁一块，看字锐不锐 | `sheet.py crop` |
| 和通过的风格帧、和参照图左右并排 | `sheet.py pair` |
| 量亮度，并拼一张 390 像素宽的「手机视角」 | `look_check.py` |
| 合成之后从成片音轨回测拍点 | `beat_probe.py --check` |

## 三、多查的九件事

### 1. 和通过的风格帧并排比

每个镜头的落定帧，和上级通过的那张风格帧用 `sheet.py pair` 左右拼在一起看：主角的位置和大小、大字的位置和字号、明暗、颜色。对不上就改到对上。必须和风格帧不一样的地方（加了运动之后调整过），在审片记录里写明，并且已经报过上级。

### 2. 连续抽帧看运动

你看不了连续播放，连续抽帧是唯一的办法。把一段的帧用 `sheet.py grid` 拼成一张，再把可疑的几张原尺寸打开。对每个主动作问：

- 东西的位置是一点点变的吗？有没有哪两张之间突然跳了一大截（瞬移）？
- 有没有哪一张突然全黑、全白、或者空了？
- 到位之后，有没有又弹回来一下？（只有「落地」类动作允许一点点。）
- 落进槽位的东西，落定后和界面严丝合缝吗？悬着的时候有没有盖住旁边的字？
- 镜头的轨迹是一条顺的线吗？有没有来回、抖？
- 几个元素依次动的时候，是错开着同时进行的，还是一个完全停了下一个才动（太呆），还是全部一起动（太乱）？
- 两组东西交换位置时，有没有哪一帧两组同时待在同一排槽位上、字叠在一起？（范例片第三轮审片抓到过。）

对每个接缝再问：

- 有没有哪一帧，主体被切成两半、两种颜色？（`参照图\反例_转场切成两色.jpg`）
- 有没有两层画面同时叠着、看起来脏的帧？有几帧？（第三版有一处叠了两三帧，设计师列为已知瑕疵；范例片改成在接缝那一帧整个换掉。）
- 接缝是不是写在拍上？甩镜和推进，拍点那一帧前后正在换画面、拍后约 0.3 秒收住，是正常的；硬切要正好在拍上。
- 甩镜的那零点几秒里，有没有半边是黑的？（前后两个镜头要同时画得出东西。）

合格的连续帧长什么样：`参照图\正例_接缝连续帧.jpg`。

### 3. 三维里的字清不清楚

每个推近的镜头，从渲出来的帧上把主角那块界面用 `sheet.py crop` 按 100% 裁出来看（参照 `参照图\正例_文字锐度裁切.jpg`）：

- 字的边缘是干净的，还是有方块、发虚？
- 斜着的界面上，离镜头最近的一行和主角那一行，哪个清楚？（应该是主角那一行。）

缩略图和整帧上都看不出字糊不糊，必须裁出来。字糊了先查截图的倍率：镜头推得比截图倍率还近时，抽帧会打一行提醒，照它说的提高这一页的截图倍率，或者别推那么近。不要去调景深。

### 4. 亮度和手机宽度

「整体偏暗、手机上看不清」是这类片子最常见的毛病，现在有数可量。对每一轮的落定帧跑 `look_check.py`，它量四个数（亮度按 0 到 100 算）并拼出手机视角的图：

| 量什么 | 怎么判 |
|---|---|
| 平均亮度 | 暗场镜头低于 9 是偏暗，低于 6 手机上基本看不清 |
| 主体亮度 | 画面中间那一块 |
| 亮部（最亮的 1% 像素） | 低于 40，说明字和色块都发灰 |
| 死黑占比 | 超过 60%，说明大半个画面是黑的 |

参考数：第三版的暗场风格帧平均亮度在 6.6 到 8.8，当时的评审意见正是「整体偏暗」；范例片的暗场镜头在 13 到 18。两版的手机视角并排：`参照图\认可版对范例_手机宽度.jpg`。亮场镜头要告诉工具按亮场判（手册里有写法）。

数字过了，再用眼睛看拼出来的手机视角图：每一格的主体认得出是什么吗？大字、副句读得出吗？落款那一格，产品名和标语读得出吗？

### 5. 对拍

- **算一遍**：稿子里每个垫片的拍数，和分镜表的拍号对得上吗？前一个镜头的终点等于后一个的起点吗？（对不上时抽帧会提醒。）
- **看一遍**：每个带「那一下」的动作（主陈述切入、图标撑开、每次落位、按钮按下）抽它那一拍的前一帧、当帧、后一帧。那一下是在拍上吗？
- **音效**：每个动作的音效，是和画面共用同一个参数对象写出来的吗？画面最后一次改动之后，声音重新混过吗？
- **成片回测**：合成之后跑 `beat_probe.py --check`。看**整体偏移**，超过 1 帧就是没对上。你点名的个别几拍上如果叠着音效，量到的可能是音效，差一两帧是正常的。
- 核出来的数字写进制作记录的「节拍数据」。

### 6. 演示数据再核一遍

截图阶段核过一次（工具写的「截图核对清单」加逐张看图）。整片阶段镜头推近了、界面放大了，原来看不清的小字现在看得清了。从成片帧里把每个镜头里**读得出来的每一行界面文字**过一遍：有没有不该露的（清单在[产品简报](产品简报.md)第四节）。

### 7. 文案逐句核

- 每句大字和副句，对回卖点表的行号，一句一句对。
- 每句话的证据，在同一个镜头里、同一时刻看得见吗？大字出来的时候，作证的那块界面是清楚的吗？
- 画面上有没有错别字、多余的标点、英文和中文之间漏的空格？大字有没有因为放不下被自动缩小（抽帧时会提醒）？
- 落款的标语和官网原文一个字一个字对。网址对。

### 8. 数数

把这张表填出来（制作记录模板的「审片记录」里已经有这张表）。数字对不上规矩的，改。

| 数什么 | 规矩 | 你的 |
|---|---|---|
| 镜头数、总时长 | 30–45 秒 7 到 8 个镜头 | |
| 主角不是真实界面的镜头数 | 只有落款 | |
| 亮场镜头数 | 不超过 1 | |
| 全屏级冲击的次数和拍号 | 不超过 3，隔开 | |
| 每句大字完全出现后的停留秒数 | 每句不少于 1.2 秒 | |
| 主陈述落定后的静止秒数 | 全片最长的一次静止 | |
| 落款全部落定后的静止秒数 | 不少于 2 秒 | |
| 第一句大字出现的秒数 | 头几秒先让界面出场 | |
| 用了几种主动作、几种转场，有没有重复 | 主动作不重复；转场不连用同一种；不用淡入淡出 | |

范例片填出来的样子：7 个镜头 40.65 秒；亮场 1 个；冲击 3 处（第 32、40.5、72 拍）；最短的一句大字停约 2.0 秒；主陈述静止约 3.4 秒；落款静止约 3.4 秒；第一句大字 5.3 秒；主动作 7 种不重复；转场有一处连用（它自己列成了已知瑕疵）。

### 9. 第一秒和最后一秒

- 抽第 0.3、0.6、1.0 秒：画面上有东西、并且在动吗？
- 落款镜头开头：图标出现之前，有没有一段空画面？
- 抽最后 0.5 秒：是静止的落款吗？配乐淡出之前画面有没有先黑掉？

## 四、判例自检和独立审片

**判例自检报告**：全片自审的最后一步，对着[审美判例](审美判例.md)逐条过，按它文末的格式写。五道判断题（主1、主2、画2、动1、拍1）即使写「过」也要写依据。

然后照[验收](../验收.md)的做法给自己打分、挑出最差的三处，能改的改掉再交。挑最差三处时别只挑版面上的小毛病，先问：哪个镜头的主角最弱、哪句话的证据最弱、哪个动作最说不清在演什么。

**你是被派来当审片员的**，除了[验收](../验收.md)「独立审片」里的要求：

- **先看参照图再看片子。** `参照图\反例_全片连看.jpg` 和 `参照图\正例_全片连看.jpg` 并排看过，读过[总纲](总纲.md)第三节，再开始。
- **不看制作者的自评分和自检报告。** 你拿到的只有帧、文案、产品简报、通过的风格帧和这份教材。先入为主会让你跟着它打分。
- **版面问题照挑，但必须另外回答这六道题**，每道写理由和帧：
  1. 遮名检验：遮住产品名，看得出这是个什么产品吗？哪几个镜头看不出？
  2. 作证：有没有哪句大字，画面上找不到给它作证的东西？
  3. 每个镜头的主动作在说什么？有没有哪个只是「东西在动」？
  4. 换名检验：有没有哪个镜头、哪句话，换成别的产品照样成立？
  5. 把这条片子和两张参照图放在一起，它更像哪一张？像在哪？
  6. 最弱的两个镜头是哪两个？哪一段最想划走？
- 用第三节的九件事各查一遍（工具你也可以跑，只读不改），用[风格帧](风格帧.md)的评分表给落定帧打一次分。
- 意见仍然分「必须改」和「建议改」。产品片的「必须改」多一类：**主角不是产品、话没有证据、演示数据露了不该露的、文案超出官网的说法。**

## 五、渲完必须从成片里再看一遍

这是硬规矩，不是可选项。

**真实的经过**：做范例片时，改了镜头的画面之后直接重跑渲染。渲染判断一段要不要重渲只看时间表，看不出画面代码改没改，于是已经渲好的分段被跳过了。成片里还是旧画面，成片体检照样全部通过。是后来把成片和第三版并排对照时才发现的。

所以：

1. **改了画面再渲，加 `--fresh` 整片重渲**，或者用 `--from --to` 只重渲改过的那几秒。渲染时如果提醒「跳过的 n 段是在画面代码最后一次改动之前渲的」，照它说的重渲。
2. **合成之后，用 `sheet.py video` 直接从成片文件抽帧**：每 0.5 秒一张的全片连看，加每个接缝的连续帧。拿它和你最后一轮审片的帧比：是同一个画面吗？
3. 用成片抽出来的帧，把第三节的第 3、4 两件事（清晰度、亮度和手机宽度）再做一次。压缩会吃掉暗部的细节。
4. `check` 照跑。它会多查一项「音轨不是静音」。派单要了无配乐版的，两条成片都要过，并且确认画面是同一条。
5. 跑成片回测（第三节第 5 件）。

「审片阶段的帧没问题」和「成片没问题」是两件事，报告里分开写。

## 六、交付报告多写的几段

在 `SKILL.md` 的交付报告格式之外，加：

```
和通过的风格帧的差异：逐个镜头写「一致」或「改了什么、为什么、上级是否知道」。
节拍核对：曲子、拍长、进满的拍号；成片回测的整体偏移。
亮度：每个镜头的平均亮度（look_check 的数）；手机视角图的路径。
数数表：第三节第 8 项那张表。
判例自检：报告在哪；「不过」的几条现在的状态；有意不照做的几条和理由。
成片复看：从成片抽的全片连看和接缝连续帧的路径；和最后一轮审片帧是否一致。
已知瑕疵：改不了或来不及改的，逐条写在哪一秒、是什么、影响多大。能改的不许列在这里。
未验证：曲子的气质；配乐接缝的听感；每条音效在成片里听不听得见；连续播放时甩镜、冲入这类快动作的观感；发布平台二次压缩之后的清晰度。
试听片段和建议上级重点看的帧。
```

## 你最容易在这一步出的错

- **跑了 `probe`、对了风格帧，就当审完了。** 这两样查的是「没做错」。
- **只看自动取的那十几张。** 产品片的问题多半藏在运动和接缝里，不点名取不到。
- **看到 `[注意] [镜头包]` 的提醒不处理。**
- **改了画面，重渲时没加 `--fresh`，然后看着全绿的体检表交了。**
- **只看审片阶段的帧，不从成片里抽帧。**
- **抽到动作中途的一帧，就判成缺陷，或者反过来把真缺陷当成「还在动」。** 前后各补几张再判。
- **看拼图不看原图。** 字糊、压字、露馅，拼图上都看不出来。
- **亮度只看数不看图，或者只看图不看数。** 两样都要。
- **自检报告整篇写「过」。**
- **当审片员时只挑版面。** 教程试片里那位审片员挑出了 16 条，全是版面和节奏上的，对教程片够用；对产品片，第四节那六道题才是主要的。
- **把推测写成事实。** 教程试片里，审片员看到光标压在另一个按钮上，就写「坐标写错了」；其实坐标是对的，那一帧光标正在路上。写你看到的现象，原因是推测的就写明是推测。
