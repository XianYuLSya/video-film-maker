# 风格帧：先把方向给人看

风格帧是每个镜头「落定那一刻」的静帧：机位、打光、真实界面、大字都在最终的位置上，只是还没有运动。全片七八张。**出完自评，交给上级，等到明确的「通过」再做整片。** 这是全流程唯一必须停下来的地方，原因见[总纲](总纲.md)第五节。

## 一、出哪些

1. **每个镜头一张**，取大字和主角都落定的那一刻。落款取全部落定后的最后一帧。
2. **开场镜头和主陈述镜头，各出两到三个变体。** 这两个镜头最吃判断，你自己挑不准，所以给上级挑。变体之间要真的不同：换机位、换构图、换明暗、换字的位置。字号差 4 像素不算变体。
3. **一张总览**：所有风格帧按顺序拼在一起（每张 960 像素宽左右）。看的是它们像不像同一条片子。
4. **一张手机宽度拼图**：每张缩到 390 像素宽，原样拼，不放大。看的是在手机信息流里立不立得住。

风格帧是在真工程里渲出来的，不另外用别的工具画。做法是从 `--kind product` 的起步工程开始，先把每个镜头的「落定状态」写出来（机位、光、界面、大字），入场和转场以后再补；然后在每个镜头落定的时刻抽静帧。这样风格帧通过以后，代码直接就是成片的代码。抽帧用片场的 `stills`；总览和变体并排用 `sheet.py`，手机宽度拼图和亮度用 `look_check.py`（都在手册「审片工具」一节）。抽帧时命令行里打出的 `[注意] [镜头包] …` 先处理掉：主角出画、主角太小、大字压住主角、字放不下被缩小，它都会说。

存放：工程的 `review\风格帧\`，文件名带镜头序号和内容（`SF1_开场.png`、`SF4_主陈述_变体B.png`、`总览.jpg`、`手机宽度.jpg`）。

**静帧立不住，别指望运动来救。** 第三版的开场风格帧，设计师自己的评价是「暗底上的暗界面，静帧里悬浮感偏弱，它的戏主要在运动里」。交上去之后，反馈是「暗、闷」。一张风格帧需要你解释「动起来就好了」，它就还没做完。

## 二、自评

自评分两部分。**每一项都要对着图回答，并且写一句你看到了什么**，只填「是」或只填分数不算。写进制作记录的「风格帧评审」。

### 甲、硬门槛（有一条不过，就不许交）

| # | 问题 | 怎么查 |
|---|---|---|
| 甲1 | 除了落款，每张的主角都是真截的产品界面吗？ | 逐张说出这块界面是哪条命令截的 |
| 甲2 | 每张截图都对着清单核过演示数据了吗？ | [产品简报](产品简报.md)第四节的清单，逐张 |
| 甲3 | 每句大字都指得回卖点表里的一行吗？ | 逐句写行号 |
| 甲4 | 要读的字够大吗？陈述 80 像素以上、副句 34 以上、网址 32 以上 | 在渲出来的图上量实际的字高，不看代码里的字号 |
| 甲5 | 手机宽度拼图里，每张的主体认得出、大字读得出吗？暗场镜头的平均亮度都不低于 9 吗？ | 打开手机宽度拼图，原样看；亮度看 `look_check.py` 量的数 |
| 甲6 | 全片的亮场不超过一张吗？吉祥物、徽标图形只在落款出现吗？舞台和界面是反着来的吗（浅色界面不抄深色范例的亮场和曝光）？ | 看总览；[审美判例](审美判例.md)画10 |
| 甲7 | 底色、强调色、字体，都说得出取自产品的哪里吗？ | 对着产品简报第五节 |
| 甲8 | 有没有频道的画面禁忌、禁用的词？ | [频道规矩](../频道规矩.md) |
| 甲9 | 推近的镜头里，界面上的字原尺寸裁出来是清楚的吗？ | 把主角那块按 100% 裁出来看，不看缩略图 |
| 甲10 | 版面体检有没有错误（字出画、字太小、被裁）？镜头包的提醒都处理了吗？ | 片场的 `probe`，用 `--at` 点名风格帧的时刻；抽帧输出里的 `[注意]` |
| 甲11 | 每张的主角至少占画面宽度的三分之一吗？主角有没有被画面边缘切掉？ | 在落定帧上量主角那块的像素宽（1920 宽的图上不少于 640）；主角的四条边都在画面里。整页平视、主角只是页面上的一小条，不过（`参照图\试片反例_整页平视.jpg`；做对的样子 `参照图\试片正例_贴近一行.jpg`） |
| 甲12 | 每句大字的每一行、连同副句，后面都是暗的吗？ | 把字块那一块按 100% 裁出来：背景里没有亮界面，没有读得出的界面字。只看第一行不算，最容易出事的是第二行和副句（`参照图\试片反例_浅色界面_字压在亮处.jpg`） |
| 甲13 | 同一种版式（界面和字各在哪边）全片用了几次？ | 列一行：每个镜头的字在哪、界面在哪。同一种不超过两次，而且不相邻 |
| 甲14 | 有没有哪一句大字把主陈述提前说了？ | 把主陈述之前的每一句和主陈述并排读。意思重合的改掉，主陈述要是第一次听到这句话 |

### 乙、评分（每项 0、1、2 分，满分 20）

评分前先把这四张参照图打开放在旁边：`参照图\认可版_风格帧总览.jpg`（用户说「对」的那一组）、`参照图\正例_总览.jpg`（范例片）、`参照图\正例_手机宽度.jpg`、`参照图\反例_全片连看.jpg`。

| # | 对着图回答 | 2 分 | 1 分 | 0 分 |
|---|---|---|---|---|
| 乙1 | **遮名检验**：遮住产品名和徽标，每张看得出这是个干什么的产品吗？ | 除落款外每张都看得出 | 有一两张看不出 | 三张以上看不出 |
| 乙2 | **作证**：每张里，给大字作证的东西能用手指出来吗？它是清楚的、亮的吗？ | 每张都指得出，而且是画面里最清楚的地方 | 有一两张指得出但发虚、偏暗、太小 | 有指不出来的 |
| 乙3 | **主角够大**：手机宽度下，主角那块界面还认得出是什么吗？ | 每张都认得出 | 有一张只剩一团 | 两张以上认不出 |
| 乙4 | **焦点唯一**：每张里清楚又明亮的地方，除了大字只有一处吗？ | 每张都是 | 有一两张有两处在抢 | 多张到处都清楚，或者到处都虚 |
| 乙5 | **亮度**：和 `正例_手机宽度.jpg` 并排，你的暗场镜头比它暗吗？ | 不比它暗 | 有一两张明显更暗 | 整体发闷，像蒙了一层 |
| 乙6 | **字的位置**：相邻两张，机位和字的位置都不同吗？字后面是干净的吗？ | 都不同，字后面干净 | 有一处相邻两张版式相同，或有一张字后面透出能认的界面字 | 多处版式重复，或字压在清楚的界面上 |
| 乙7 | **是一条片子**：总览里，各张的底色、字、光是同一套吗？同时又没有两张构图一样吗？ | 是 | 有一张像是别的片子里的，或有两张构图雷同 | 风格散，或者张张一个样 |
| 乙8 | **主陈述最强**：总览缩小了看，第一眼落在哪一张？ | 落在主陈述那张 | 落在别的某一张 | 没有哪一张突出 |
| 乙9 | **落款是海报**：落款那张单独拿出来能当海报吗？四样东西（徽标、名字、标语、网址）大小关系清楚吗？ | 能，关系清楚 | 能，但有一样偏小或挤 | 像没排完 |
| 乙10 | **是这个产品自己的**：换名检验。把产品名换成竞品，这几张还成立吗？和范例总览并排，除了手法，颜色、界面、文案都是这个产品自己的吗？（做的就是范例那个产品时，这一项只做换名检验） | 换名后不成立；皮是自己的 | 有一两张换名后照样成立 | 多张换给谁都行，或者把范例的配色、句式搬来了 |

打完分，再写三句话：

- **最弱的两张是哪两张，弱在哪。**（哪怕你觉得都不错，也要挑出两张。）
- **如果只能重做一张，重做哪张。**
- **两个变体镜头，你各推荐哪个，为什么。**

### 分数线

- 甲全过，乙自评 **16 分以上，并且没有 0 分的项**，才交上去。不到就先改。
- 上级另派了审片员用这张表评，乙低于 **14 分**的退回重做。
- 这两条线是初定的，还没有被真实的片子验证过。
- **分数只决定能不能交上去，不决定能不能做整片。** 做不做整片，只看上级那句「通过」。被否的那一版，做它的剪辑师自评 8.5 分。

## 三、交上去

用 `ask_parent`，一次把上级要定的东西交全：

```
风格帧节点，请确认后我再做整片。

1. 风格帧：<目录>。总览 <路径>；手机宽度拼图 <路径>。
2. 变体：开场 A/B/C <路径>，我推荐 <哪个>，因为 <一句话>；主陈述 A/B <路径>，我推荐 <哪个>，因为 <一句话>。
3. 文案全文（每镜头一句）：<贴出来>
   主陈述候选：① <…> ② <…> ③ <…>。风格帧按 <第几条> 做的。（派单已定主陈述时，这一行写「主陈述按派单」）
4. 曲子：<曲名>，<每分钟多少拍>，第 <几> 拍进满。试听片段 <路径>。未验证：曲子的气质合不合适。
5. 自评：甲全过；乙 <几> 分。最弱的两张是 <…>，弱在 <…>。
6. 想请你定的：<列成问题，比如「亮场用图标的米白还是官网的纸色」>
```

等回复的时候可以做：核对其余页面的截图、把音效表的骨架列出来。**不要开始做运动。**

## 四、被退回

- 把批注的原话记进制作记录。
- 批注说得含糊（「这张不够有分量」）时，先问清楚指的是哪一张、是嫌主角小、嫌暗、还是嫌没东西，再动手。猜着改，容易改错对象。
- 逐条改，改完重新自评，只把改过的几张加新的总览交上去，写明每条批注是怎么改的。
- **退回两次还不过，停下来请上级升级**（[派单](派单.md)里有升级的办法）。同一处来回磨第三遍，多半是你看不出问题在哪，再磨也是浪费。

## 五、通过之后

- 把上级「通过」的原文和日期记进制作记录。
- **通过的风格帧就是整片的标准。** 做运动时，每个镜头落定的那一帧要和通过的风格帧一致：位置、大小、明暗、颜色。审片时并排比（见[审片](审片.md)）。
- 不许在通过之后「顺手优化」构图和配色。整片阶段发现某张必须改（比如加了运动之后字被挡），改之前报给上级，附改前改后的对比。
- 「通过」只是方向过了。整片照样要走自审、独立审片和验收。

## 你最容易在这一步出的错

- **只出一套，不给变体。** 觉得自己做的那个就是最好的。你判断不了，所以要给上级挑。
- **变体差别太小。** 三个变体只是字的位置挪了 40 像素。
- **自评全给 2 分。** 每一项都写一句「看到了什么」，最弱的两张必须挑出来。
- **没等「通过」就开始做运动。** 做了也可能全废。
- **拿运动当借口。** 见第一节那个例子。
- **截图没核就拿来做风格帧。** 风格帧会被拿去给用户看，演示数据露了馅是事故。
- **浅色界面照着深色的范例做。** 见甲6。
- **照着范例的总览一张张对着摆。** 范例是七个镜头，不等于你的产品也该是这七个镜头。你的镜头从你的卖点表来。

## 第一次让 DeepSeek 独立做的那条片子出了什么（2026-11-11，「一键发布」，浅色界面）

这一节是真事，放在这里是因为下面每一条，做的人自评时都给了自己满分。

- **第一轮风格帧自评 17 分，被退回。** 七张里有六张，主角只是一整页表单里的一条细线，缩到手机宽度什么都读不出；开场是一张平视的整页截图。自评的乙3（主角够大）给了 2 分。教训：乙3 不要凭感觉答，按甲11 去量。
- **第二句大字把主陈述说完了。**「填一次标题，四个平台都用。」后面隔三个镜头才是主陈述「填一次，四个平台。」，到那儿已经没有落点。见甲14。
- **话和画面对不上。** 大字是「四个平台同时开始」，画面上四行全是「已发布」。落定帧上界面的状态要和这句话说的是同一刻。
- **浅色界面的字里透界面做不干净。** 试了三版：放大了透出来是小字的碎片和横线（`参照图\试片反例_浅色界面_字里透碎字.jpg`），把小字藏掉只剩一片灰。这个界面除了 3 像素的彩色顶边和很淡的绿条，没有能排进笔画的色块。最后经上级同意用了实心大字。**浅色、没有大色块的界面，主陈述可以用实心大字，在「有意不照判例做的地方」记一笔；不要交一张脏的字里透界面。**
- **为了躲「黑带」把压暗调淡，字就压在灰纱上了。** 浅色界面上，字底下那层压暗看起来像一条黑带。把它调淡（`scrim` 0.6）以后字后面是一层灰，灰字压灰底（`参照图\试片反例_浅色界面_灰纱.jpg`）。做对的办法是机位：字放在界面的一侧（`left`、`right` 版式），让界面从亮处斜着退进暗处，暗的那一侧放字（`参照图\试片正例_浅色界面_字在暗侧.jpg`）；用上下版式时，让界面被景深虚掉的近边落在过渡区里。压暗的强度不动。
