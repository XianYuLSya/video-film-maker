# 素材：图从哪来、别人的视频怎么看懂

## 图一律交给 Codex 画师

角色贴纸、场景插画、梗图、封面底图，都派给 Codex 方画（用户认可它的出图质量，放开让它多画）。你不生图，也不用代码硬画人物。

**画图很慢（一张一到三分钟），而且常常要返工，所以稿子定下来就立刻派，和写画面同时进行。** 图没到之前，场景里先用占位（积木库的角色图组件在找不到图时会画虚线占位框），不要干等。

### 你有派单工具时（`futureaide_run_agent`）

建一位画师：`target: "codex-desktop"`，`lifetime: "persistent"`（要来回改图，一次性的会丢上下文），模型和强度按上级派单里给的传（没给就不传）。派单写清这些：

```
你是画师。用你内置的图像生成（image_gen）给 B 站视频「<片名>」画素材。博主是<博主名>，频道的固定角色是<角色名>（参考图：<路径>）。
所有文件存到 <作品目录>\art\raw\，文件名按下面的清单，PNG。

画风参考（只学画风，不要画进图里）：
  <片场>\assets\char\victory_c0.png、point_c0.png、face_smug_c0.png
要点：Q 版 2.5～3 头身，深海军蓝粗描边（线宽一致），平涂上色，少量网点阴影，配色柔和，表情生动。

<借用社区角色时> 角色身份严格照参考图：<角色名 = 出处，参考图路径>。先画一张设定图 <名字>_sheet.png（白底），画完停下来报告，等我确认后再画其余的；之后每张都引用设定图锁定形象。

角色贴纸：每张只画一个角色、全身、居中、四周留白、不出画；背景画纯色 #00FF00 绿幕，角色身上不要出现绿色，发丝和缝隙不要彩边。不要文字、不要水印、不要地面阴影、不要背景物件（清单里写明的道具除外）。工牌、屏幕这类地方留空，不写字。
场景插画：16:9，不要文字。
封面：文字逐字照写，不加别的字，四边留 5% 安全边距。
全部：不用红色圆盘配放射光芒，要爆发感用漫画集中线。不需要你做抠图、缩放这些后处理，保持原样输出。

清单（文件名｜内容｜背景）：
  fish_work.png｜大肥鱼坐在电脑前打字，专注｜绿幕
  scene_office.png｜四个工位的办公室，暖色调｜完整背景
  ……
做完用 report_parent 交文件清单；有拿不准的用 ask_parent 问我。
```

要点：

- **借用梗里的角色，先定形象再画姿势。** 找到社区通行的形象和原设计者，把参考图路径和出处写进派单，先画设定图。设定图在交付节点报给上级过目，确认后再批量画姿势。真实教训：有一次没确认就画了六个姿势，用户一句「形象不对，用最火的大肥鱼网络形象」，全部作废重画。大肥鱼的参考图在 `<工作区>\work\FutureAideControl介绍片\art\references\`，出处是画师 ZipZipPipe。
- 画师交回的绿幕是「近绿色」而不是纯绿，没关系，片场的抠图脚本按「绿比红蓝高多少」来抠。画师来问要不要做后处理，答「不需要」。
- 画师交回的图逐张看：身份特征对不对、有没有多余的肢体或文字、有没有出画。不对的让它单张重画。

### 你没有派单工具时

把上面的清单按同样格式写进交付节点的报告，请上级代派；图到之前用占位继续做。

### 把原图处理成片中素材

```
.\film.cmd art            # 处理 art\raw\ 里的新图
```

角色贴纸：抠掉绿幕、收紧边缘、加纸白描边、生成三帧手绘抖动，存进 `film\public\art\`，尺寸登记进 `film\src\chars.json`。场景插画只缩放。具体参数和命名规则见片场 README。处理完用看图工具检查抠图边缘有没有残留绿边、有没有被抠穿。

（`art` 命令以片场 README 为准；README 里没有这条时，用 `film\scripts\prep_chars.py`，用法写在脚本开头。）

## 角色和公共素材

每部片子自带，不用另找：

- 角色十二个姿势（片场自带的是占位图，换成你自己的角色，同名文件放进 `film\public\char\`）：`think`、`peek`、`read`、`victory`、`wave`、`point`、`face_shock`、`flip`、`toolbox`、`explore`、`fish_happy`、`face_smug`。
- 字体：思源黑体、思源宋体、得意黑（大标题）、站酷快乐体（气泡）、Inter、JetBrains Mono，都是开源授权。
- 音效三十多种、纸纹理、通用片头片尾。
- 配乐在片场内置曲库（Mixkit 免费商用）。

## 真实截图当证据

聊天记录、群友反馈、测试结果这类截图可以放进片子当证据，规矩：

- 昵称、头像、群等级、QQ 号、别人电脑上的地址栏和书签，全部裁掉或用色块盖住。裁剪和遮盖之外不改图，不 P 结果。
- 截图发灰、对比度低的，先用脚本把图本身调好（拉对比度）再放进画面，不要在画面里用滤镜硬压。
- 截图旁边标一句来源（「群友原话 · 已隐去昵称」）。
- 别人的截图能不能公开，在交付报告里提一句请上级确认。

## 看懂一条现成的视频（重做别人的片子、参考录屏时）

原片只当素材来源，声音和画面都不直接用。三步看懂它：

**1. 看章节表**（有的视频自带）：

```
ffprobe -v error -show_chapters -of json "<原片.mp4>"
```

**2. 抽帧拼图看画面**：每 3 秒一帧，16 格拼一张，每格左上角带时间码。

```
ffmpeg -v error -y -i "<原片.mp4>" -vf "fps=1/3,scale=480:-2,drawtext=fontfile='C\:/Windows/Fonts/arial.ttf':text='%{pts\:hms}':x=6:y=6:fontsize=22:fontcolor=yellow:box=1:boxcolor=black@0.6,tile=4x4" "<输出目录>\sheet_%02d.png"
```

拼图用来找位置；要读界面上的字，再按秒数单抽原尺寸的帧：`ffmpeg -ss <秒> -i "<原片.mp4>" -frames:v 1 "<帧.png>"`。

**3. 语音转文字**：

```
ffmpeg -v error -y -i "<原片.mp4>" -vn -ac 1 -ar 16000 "<输出目录>\audio16k.wav"
& "<ASR 工具目录>\venv\Scripts\python.exe" "<ASR 工具目录>\transcribe.py" "<输出目录>\audio16k.wav" "<输出目录>\asr.json" medium
```

转写会有错字，术语要对着画面核一遍。如果报模型路径打不开（模型目录是符号链接），把模型文件拷成普通文件放到一个目录里，把那个目录当模型名传进去。

看懂之后，把原片讲了哪些事、按什么顺序、哪些是事实哪些是个人做法，整理进 `制作记录.md`，再按 [写稿.md](写稿.md) 重写。原片里和频道规矩冲突的做法（换区、编地址之类）不搬，但要分清「不能教的做法」和「旁边那个该教的知识点」，别一刀切。

## 界面还原的依据

模拟某个软件的界面时，依据按可靠程度排：该版本的源码或安装包里的界面文字 > 真实截图或录屏 > 官方文档。都没有的界面元素画成示意，并写进交付报告的「未验证」。不凭记忆画按钮和菜单。
