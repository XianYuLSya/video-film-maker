# 验收：自己先把片子看过一遍

这份流程是整套做法里最要紧的一环。2026-11-07 有四段开场交给过 DSH 做，没有逐帧看图就交了，结果构图挤在一边、文字竖排断行、纸张挡住角色，用户一眼看出「质量明显差了一大截」。画面是用绝对坐标写的，一个字宽变了，旁边的箭头、标签就会错位，**只有把帧渲出来、原尺寸逐张看，才看得见**。日志全绿、类型检查通过，都说明不了画面是对的。

你有看图工具（`read_image`），能直接看 PNG。验收就靠它。

**做的是品牌片、产品片**：这一份照做，另外再读 [产品片/审片](产品片/审片.md)。那类片子没有口播，要自己点名取帧，还要多查运动、三维里的文字清晰度、亮度、对拍和演示数据，并回答几道版面体检量不出来的判断题。

## 三道关

| 关 | 什么时候 | 做什么 | 过关标准 |
|---|---|---|---|
| 稿子体检 | 稿子写完、每次改稿后 | `film.cmd lint` + [写稿.md](写稿.md) 第七节自查 | 错误为零，警告逐条看过 |
| 画面审片 | 每写完一个场景；全片写完；每次改动后 | 抽帧 → 原尺寸逐张看 → 记问题 → 改 → 复查 | 审片记录里没有未关闭的问题 |
| 成片体检 | 合成出 MP4 之后 | `film.cmd check` + 从成片抽帧复看 + 切试听片段 | 体检表全部通过，未验证项写明 |

整片渲染最费时间（六分钟的片子约 15–30 分钟），所以**画面审片必须在整片渲染之前做完**。渲完才发现错字，就是整片重来。

## 画面审片怎么做

### 1. 先看范例，心里有个标准

开工第一次审片前，先打开三四张旧片的成片帧，记住「合格」长什么样：元素多大、留白多少、字多大、一屏放几样东西。

- 本频道已发片子的成片帧（`<工作区>\work\` 下各部片子的 `review\final_zh\`，派单会点名看哪几部）
- 示范片的合格样本帧：`<片场>\template\review\final_zh\`（正片）和 `final_short\`（竖屏短版）。这一组是用积木库做出来的，最接近你要交的东西，重点看它
- 积木陈列片的帧：`<片场>\_gallery\`

### 2. 先让机器筛一遍，再抽帧

```
.\film.cmd probe zh --round r1             # 自动量版面：出画、压字幕、字太小、文字重叠、被裁切
.\film.cmd review zh --round r1            # 全片：每个标记之后、每句结尾、每章开头各一张
.\film.cmd review zh --round r1 --only cold,how    # 只抽这几章
.\film.cmd stills FilmZh 12.5 30 31.2      # 指定秒数补抽
```

`probe` 的结果在 `review\<轮次>_zh\probe.md`（目录名自动带版本后缀，短版是 `<轮次>_short`）。「错误」必须改掉；「提醒」逐条看，是问题就改，不是问题（比如刻意叠放的装饰字）在审片记录里写一句为什么不改。**probe 只量得出文字的位置和大小，量不出构图好不好、内容对不对、图有没有挡住字**，所以它通过了也照样要逐张看图。

**每一轮都是先 `probe` 再 `review`，用同一个 `--round`**，这样每轮目录里都有 `probe.md`，接手和审片的人一看就知道这一轮体检过没有。

`review` 的帧存在 `review\<轮次>_zh\`，文件名是「秒数_句id.png」，同目录的 `index.md` 列出每张图对应的秒数、章节、句子、刚念到的标记、当时的字幕和整句原文。

### 3. 逐张看

按 `index.md` 的顺序，**每一张都用看图工具打开原图**，对着那一行的句子和标记看。不拼缩略图代替：缩成九宫格之后，「字折行压到卡片底边」「标签被图盖住」这类问题看不出来（真实发生过，是上级放大单帧才发现的）。

判断「这一刻画面上该有什么」，对照 `制作记录.md` 的分镜表（每句、每个标记对应画面上发生什么）。

两个容易误判的地方：

- **抽帧是在标记之后 0.6 秒取的，有的元素这时还在淡入。** 看到半透明、没到位的东西，先用 `stills` 在前后 0.3 秒各补抽一张再判断，别把「动画刚开始」当成「没出来」，也别把真没出来的当成动画。
- **光标可能正在路上。** 抽到的一帧里光标停在别的按钮上，先在它该点下去的那一刻（场景里光标落点的时刻）补抽一张：落点对，就是路过；但路过也要改路线，别让光标在念「点删除」的时候从「取消归档」上面横穿过去，观众看到的就是指错了。
- **范例帧和你自己的帧文件名长得一样**（都是「秒数_句id.png」）。看范例时认准目录，别把示范片的画面当成自己的。

每张图问自己这几组问题：

**A. 这一刻该出现的东西出现了吗**

- 刚念到的这个标记，画面上有没有对应的变化？出现的东西和这句话说的是一回事吗？
- 画面上的字、数字、按钮名，和稿子、和事实表一致吗？有没有错别字？
- 该消失的东西消失了吗？上一句的说明文字有没有赖着不走、挂到这一段？
- 状态对不对？（例：订阅成功之后，页面上还留着「升级」按钮；任务已取消，状态点还在转）

**B. 文字**

- 有没有字贴到卡片边、出了卡片、出了画面？四边留白够不够？
- 有没有本该一行的字折成两行、竖着断开？
- 有没有两段文字叠在一起，或者字被图、被角色、被窗口盖住？说明牌有没有盖住它指的那个按钮或旁边的字？光标有没有盖住要观众记住的按钮名？（这类「东西压住字」`probe` 量不出来，只能靠眼睛，每张都专门看一眼。）
- 光标、圈选框、说明牌是不是落在口播说的那个按钮上？念「点删除」时光标停在隔壁的「取消归档」上，跟着做的人就点错了。
- 有没有东西压到底部字幕条，或者压到左上角的章节牌？
- 最小的字在手机上看得清吗？（正文不小于 28 像素、小注不小于 24 像素；模拟界面里的界面文字可以小一些，但关键处要有大号说明牌）

**C. 构图**

- 画面是不是空的？换章后的头两秒只有背景、没有标题也没有内容，算问题。
- 是不是半边空着、东西全挤在一侧或一角？
- 元素之间有没有互相压着：名牌压角色、吉祥物压群号卡、印章压说明、箭头没指到该指的东西？
- 标题是不是贴到了屏幕顶？窗口滑出去有没有没滑干净、还露着一角？
- 一屏是不是塞太多？参考容量：一句大标题 + 一组卡片；或者一个窗口 + 一个角色 + 一两个说明牌。
- 几个一样的贴纸有没有一模一样地排成一排（应当左右交替翻转或换姿势）？
- 和范例帧放在一起，像不像同一部片子？

**D. 规矩**

- 模拟界面出现时，角落有没有「示意画面」？画面里用了真实数据的地方，角标不能写「数据均为示例」。
- 有没有真实的邮箱、号码、昵称、头像、二维码进了画面？假数据是不是规定的那一套？
- 有没有红色圆盘配放射线？
- 平台名和账号名写对了吗？（B 站是「咸鱼凌生」，YouTube 和 X 是 XiaYuLS，不要混写）

**E. 节奏**（看相邻几张的差别）

- 连续几张图一模一样，说明这几秒画面没动。超过 4 秒没有任何变化，就要加东西：让列举的几项一项项出来、推一下镜头、让吉祥物有个反应。
- 章节交界的前后两张：前一章的东西退干净了吗？有没有两套动画同时在退场、搅在一起？
- 换章的标题读得完吗？在每章开头用 `stills` 补抽几张（章开始后 0.3、0.8、1.3 秒），标题至少要清清楚楚停 1.2 秒。
- 各章的详略均衡吗？一章讲二十秒、另一章三秒带过，观众会觉得后面是凑数。

### 4. 记下来，改，复查

问题写进 `review\<轮次>_zh\审片记录.md`，一行一条：

```
| 帧 | 问题 | 怎么改 | 状态 |
| r1_zh\0004.90_m1.png | 「Pro 200」折行，200 压在卡片底边 | 「菲区」单独一行，Pro 200 字号 150→116，nowrap | 已改，r2 复查通过 |
```

改完之后重新抽帧（新开一轮 `--round r2`）。复查要看三处：**刚改的地方、它周围可能被挤到的元素、这一章的首尾帧**。一处改动经常把旁边的东西顶歪。重复到一轮下来没有新问题。

没问题的帧不用逐条写，记一句「r2：cold 章 14 张逐张看过，无问题」。

### 5. 给自己打分

全片审完后，在审片记录末尾写：总体打几分（十分制）、最差的三处在哪、为什么。最差的三处只要还能改，就改掉再交。这一步是逼自己用观众的眼光再看一遍。

## 成片体检

```
.\film.cmd check zh
```

它会查：完整解码有没有错、分辨率帧率编码、音视频时长和时间表差多少、响度和真峰值、字幕条数和时间有没有越界。结果在 `review\check_zh.md`，全部通过才算过。

另外从**成片文件**里再抽六到十张帧看一遍（`check` 会按你给的秒数抽）：开头、每章各一张、结尾，加上每个渲染分段交界处前后各一张（默认每 3000 帧一段，也就是第 50、100、150… 秒）。合成、拼接出的问题只有在成片里才看得到。

## 你验不了的东西，照实写

你听不到声音，也看不了连续播放的画面。所以：

- 交付报告必须有一段「未验证」：听感（配音念法对不对、配乐和人声比例、音效响不响）、连续动态（动画顺不顺、镜头晃不晃）。
- 不要把「解码通过」「响度 -14 LUFS」写成「声音没问题」。数值达标和好不好听是两回事。
- 把需要人听的部分切成试听片段交上去（新做的或改过的段落，每段不超过一分半），并列出你最拿不准的念法（缩写、数字、英文名）。命令见片场 README 的 `clip`。

## 独立审片（另一双眼睛）

自己做的东西自己看不出毛病，这很正常。上级通常会另派一位没参与制作的助手当审片员，用同一份清单把帧再看一遍，问题退回给你改。收到审片意见后逐条回应：改了的写怎么改的，不改的写理由。

如果你就是被派来当审片员的：只看、只记，不改工程；除了上面的清单，再从观众角度回答三件事——看完前 20 秒知不知道这期讲什么；哪一段最想划走；全片最差的三处。把问题帧的文件名写清楚，让剪辑师能直接定位。

- 可以读的：稿子、`制作记录.md`（分镜表告诉你每一刻该出现什么）、每轮的 `probe.md`。光看帧判断不了是不是缺陷时，可以翻场景源码弄清它本来想干什么。
- 意见写现象和后果（「光标停在取消归档上，口播说的是点删除」），可以附你看到的线索，但原因和改法由剪辑师查实，你猜的原因要写明是推测。
- 严重程度分两档：**必须改**＝不改会误导观众的操作、内容或署名有错、观众一眼能看出是破版；**建议改**＝只影响好看和专业度。

## 历史上真实查出过的问题（照着找）

这些都是旧片审片时抓到的，同类问题大概率会再出现：

| 类别 | 当时的样子 | 当时的改法 |
|---|---|---|
| 折行压边 | 卡片里「Pro 200」因为同一行东西太多折行，「200」压在卡片底边 | 拆成两行，字号调小，加不换行，四边留 40 像素 |
| 卡片挤 | 四张卡挤在一起，标题被压 | 卡加宽、间距收一点、标题字号降两号 |
| 名牌压角色 | 名牌盖在角色身上 | 名牌挪到角色旁边空处 |
| 箭头指偏 | 箭头终点落在两个东西之间 | 改终点坐标，重新抽帧确认 |
| 空舞台 | 换章后前两秒只有背景 | 标题出现时刻提前到章节开始后 0.15 秒；再补一组小元素 |
| 半边空 | 一个动画只在右半边演，左边全空 | 重排运动轨迹，让主体经过左半边；空处加说明 |
| 残留状态 | 升级成功后设置页还显示「升级到 Pro」 | 组件加状态开关，成功后显示新状态 |
| 文字赖着 | 说明文字没有退场时刻，一直挂到下一段 | 给它加上消失时刻 |
| 标题贴顶 | 一组卡片上移让位时，标题被顶到屏幕边 | 上移量减小 |
| 窗口盖角色 | 窗口滑进来把角色整个盖住 | 角色改成从窗口后面探出头 |
| 插画顶字幕 | 插画太高，底边压到字幕条 | 缩小并上移 |
| 界面字太小 | 终端字号 19，手机上看不清 | 行高和字号各加一档（24） |
| 图标看不清 | 徽标缩到 0.42 倍后认不出 | 换成专门的小尺寸图标 |
| 没滑干净 | 窗口滑出画面后还露一角 | 加大滑出距离 |
| 重复元素 | 四个一样的角色朝向完全相同 | 隔一个左右翻转 |
| 重复角色 | 插画里已有这个角色，旁边又叠了一个同样的 | 删掉多余的 |
| 标题跟着镜头跑 | 标题放在镜头里，推近时被推出画面 | 标题移到镜头外的固定层 |
| 被前景挡 | 文字落在栏杆、窗框这类前景后面 | 文字挪到前景之外 |
| 镜头互抢 | 两个镜头关键帧时间重叠，画面被拉回全景 | 删掉多余的那个，错开时间 |
| 退场搅在一起 | 本章淡出和下一章入场同时发生 | 两个动作错开 0.25 秒以上 |
| 角标和事实矛盾 | 画面是真实数据，角标写「数据均为示例」 | 角标只写「示意画面」（这次是整片重渲的代价） |
| 平台名混写 | 「B 站 / YouTube @XiaYuLS」写在一行，B 站账号其实是咸鱼凌生 | 拆成两行各写各的 |
| 编的例子 | 演示用的提问是编的，和旁白里的真实经历对不上 | 换成真实发生过的那句 |
| 图表小注压条 | 条形图的小注落在彩色条上，读不清 | 小注挪到条的下方 |
| 刻度爆炸 | 数值上千的条形图按每格一根刻度线，画了上千根 | 关掉刻度 |
| 截图发灰 | 真实截图裁出来发灰，对比度低 | 先把图本身的对比度处理好再放进画面 |
| id 撞车 | 气泡和口播句用了同一个 id，抽帧报「某句里没有某标记」 | 气泡统一用 q 开头 |
| 光标指错按钮 | 把旧界面件整体缩小后，光标落点的坐标换算没跟上，念「点删除」时光标停在「取消归档」上 | 查清换算，把窗口里所有落点、圈选、说明牌逐个抽帧核对 |
| 换章标题读不完 | 换章过场只给了 1.1 秒，标题实际只停 0.5 秒 | 加长过场，章间留白不够就加大配音的换章停顿 |
| 窗口压字幕 | 整屏模拟窗口的下沿伸到字幕条后面 | 窗口缩小，底边收到 y 930 以上 |
| 说明牌压字 | 说明牌盖住它旁边的回复文字、对话气泡 | 换到目标的空白一侧，或加大间距 |
| 卡片先出一张像漏画 | 两张卡先出第一张时偏在左边、右半屏全空 | 给没出现的卡留占位，或单卡先居中 |
| 详略失衡 | 第二章 20 秒、第三章 3.3 秒带过 | 短的那章补内容，或并进别的章 |
