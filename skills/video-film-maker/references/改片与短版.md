# 改已有的片子、出竖屏短版

## 改片

### 先弄清牵一发动多少

全片的时间只有一个来源：稿子经过配音生成的时间表。场景里所有时刻都是从句子和标记取的相对时间。所以：

| 你改了什么 | 要重跑什么 |
|---|---|
| 稿子里任何一个字（包括标点、标记位置） | 配音 → 抽帧看受影响的场景 → 整套声音（配乐、音效、混音）→ 渲染从改动处往后的全部分段 → 合成 → 体检 |
| 只改画面（坐标、字号、配色、换图），稿子没动 | 抽帧复查 → 只重渲覆盖到的分段 → 音效清单变了就重跑声音 → 合成 → 体检 |
| 只改念法表 | 配音（只重新合成受影响的句子）；时长变了就同上面第一行 |
| 只改配乐编排 | 声音 → 合成 → 体检，不用重渲画面 |

改了稿子，后面每一句的起止时间都会平移。画面因为是按标记对点的，会自动跟着走，**但下面这些不会自动跟，要人工查**：

- 场景里手写的绝对秒数（本来就不该有，见到就改成从标记取）。
- 画面上写死的时间文字、「第几步／共几步」这类编号、章节数量。
- 章节交界的收尾动作：插入新章节后，前一章的「下一章是谁」、段尾拉回镜头、退场音效，都要挪到正确的位置。
- 配乐编排里引用的句子和标记（片场会在找不到时报出是哪一段，不会悄悄用旧时间）。

`film.cmd status` 会告诉你哪些产物比稿子旧、下一步该跑什么。改完稿先跑它。

### 步骤

1. **读原来的东西**：工程的 `制作记录.md`、创作简报、稿子、要改的场景；看几张原片的帧，记住它的样子。不要凭派单里的一句话就动手。
2. **备份将要改的文件**到 `backup_<版本>_<日期>\`（稿子、时间表、要改的场景、配音和混音文件）。只拷要改的，不拷 `node_modules` 和渲染输出。
3. **新版本用新名字**：在 `film.json` 里把成片文件名改成带版本的（如 `…_v2_1080p60.mp4`），旧成片留在原地。
4. 改稿 → `lint` → `voice` → `status`。
5. 改画面 → 抽帧审片（重点看新增段落、章节交界、所有被平移的场景各抽一两张确认没串场）。
6. `render`（只会重渲受影响的分段）→ `audio` → `mux` → `check`。
7. 成片抽帧复看：新增段落、交界处、片头片尾。
8. `制作记录.md` 里记这一版改了什么、为什么、备份在哪。

### 在片子中间加一章

- 稿子里加章节和句子；新章节一个新场景文件，登记进场景列表（按时间顺序）。
- 前后两章的场景范围是按「本章开始」到「下一章开始」取的，插章之后把前一章的「下一章」改成新章。
- 开场如果预告过「这期讲几件事」，同步改预告；回顾段同步加一条。
- 加了内容，开头有没有交代？用户看片时最在意开场是否说清了全片讲什么。

### 换主角、换例子（稿子大面积改字，但结构不变）

配音按句子文本缓存，没改的句子不会重新合成；画面按标记对点，标记名不变的地方不用动。所以改法是：稿子里改字、标记名尽量保留 → 场景里只换图标、文字和顺序 → 演示对象整个换掉的那一章重写。改动散在全片时，整片重渲是省不掉的。

旧版本整包移到 `<工作区>\clean\<日期>-<作品>-<说明>\`，不删。

## 竖屏短版

短版是正片的预告和引流（43–60 秒，1080×1920），不是把正片缩一缩。它有**自己的稿子、自己的时间表、自己的画面**。

### 稿子：`film\src\script_short.json`

只留「现象 → 证据 → 结论 → 去哪看完整的」，5–7 句：

```
1 钩子：一句最抓人的现象或结果
2–3 证据：最有说服力的一两个画面（前后对比、真实数字）
4–6 要点：三条以内，每条一句
7 去处：「完整流程，在我主页那期。拿不准的来群里问，群号在简介。」
```

- 砍掉所有「要跟着做」的步骤；步骤是正片的事。
- 能复用正片的句子就复用（配音缓存直接命中）。
- 短版不接通用片头片尾。
- 节奏更紧：`film.json` 里短版的句间停顿、字幕每条上限（12 个字）已经单独配好，不用手调。

### 画面：`film\src\short\`

- **安全区**：平台界面会盖住上下和右侧。内容放在 x 80–1000、y 240–1480 之间（以积木手册为准）；字幕条的位置由短版模板定好了，不要挪。
- 字号比横屏大一档：主标题 96–120，要点 56–60，说明不小于 40。
- 版式自上而下三段：顶部一两行大字 → 中部一个主视觉 → 下部说明或气泡。一屏只讲一件事。
- 用积木库的竖屏版式（手册里标了哪些支持 `vertical`），素材和小组件直接复用正片的，不另画一套。
- 结尾画面：正片封面缩略图 + 群号卡 +「完整教程在主页」。

### 跑

```
.\film.cmd voice short
.\film.cmd review short --round s1      # 逐张看，清单同正片，另加安全区
.\film.cmd all short
```

短版审片另外检查：有没有东西落在安全区外；字幕有没有折成两行；第一帧有没有内容（短视频第一帧就是封面）。

### 给 X 的横屏短版（派单要求时才做）

把竖屏画面放在 1920×1080 画布中间，两侧放片名和「完整教程去哪看」。两侧写账号时分开写：`B 站「咸鱼凌生」`、`YouTube @XiaYuLS`，不要写成一行。
