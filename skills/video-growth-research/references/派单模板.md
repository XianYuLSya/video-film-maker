# 派单模板（FutureAide Control 并行调研）

2026-11-10 做 FutureAide Control 介绍片时实际用过的四路分工，四份报告最后都交回来了（一份中途失败后续写完成，见「失败了怎么续」）。用 `futureaide_run_agent`，`lifetime: "persistent"`（要留着查过程、追问；`once` 交完会清掉记录），目标默认 DSH。每位只写自己的一个文件，交回 `report_parent(final: true)` 摘要。封面和角色素材另派一位 Codex 画师，见第五节；平时例行的流量密码巡检见第六节。

派单前把共用背景填好。尖括号换成本期内容。

## 共用背景（每份派单开头都放）

```
你是调查员。背景：博主「咸鱼凌生」的频道（B站为主；YouTube/X 账号 XiaYuLS，只做中文版），定位「让普通人，用上前沿生产力」，二次元、轻松、讲解细。要做一期视频介绍 <对象：一句话说清它是什么、能干什么、入口在哪>。视频目标：<流量 / 推广指标 / 私域入口，比如 QQ 群号>。今天是 <日期>。
```

## 共用规矩（每份派单结尾都放）

```
规矩：每条事实标来源 URL；拿不到的数据写「未验证」，不编数字、不把估算写成事实。页面打不开或被反爬时换路径，文末写明哪些路径失败。
产出：写入 <作品目录>\调研\<文件名>.md（中文 Markdown，只写这一个文件，不改其他文件）。做完用 report_parent(final: true) 交：主要结论 + 文件路径 + 未验证项。
```

## 一、B 站样本

```
你的任务：调研 B 站上 <品类> 类视频，什么风格和包装点击和播放更高。
1. 关键词至少覆盖：<产品名、品类词、痛点词、当下热梗、竞品与官方功能名>。每个词按综合排序和最多播放各看前 10–20 条，以 <一年前日期> 之后发布的为主。
2. 每条样本记：BV号、标题、UP 主、UP 粉丝数、播放、点赞、投币、收藏、评论、时长、发布日期、封面要素（真人脸/二次元角色/大字/对比/软件截图/箭头/数字/表情）。能看到开头的，记前 15 秒怎么开场。
3. 点击率不公开，用「播放/粉丝比」找出播放远超粉丝数的爆款，归纳标题公式、封面样式、时长区间、内容结构，以及和普通样本的差别。
4. 查 B 站官方对推荐机制、封面、标题的说明，引原文要点。
结构：一、结论（5–8 条可执行建议，按对流量的影响排序，每条附依据样本）；二、爆款样本表；三、普通样本表；四、官方说明要点；五、方法与局限。样本不少于 40 条。
```

## 二、YouTube 与 X

```
你的任务：调研 YouTube 和 X 上 <品类> 类内容，什么风格和包装点击更高。
1. YouTube：中文与英文各 20 条以上样本，以 <一年前日期> 之后为主。记链接、标题、频道、订阅数、播放、时长、日期、缩略图要素。用「播放/订阅比」找爆款，归纳标题公式、缩略图样式、时长、开头 30 秒怎么抓人；中文频道单独归纳。
2. YouTube 官方对标题、缩略图、点击率、观众留存的说明（YouTube Help、Creator Insider、Test & Compare），常被引用的 CTR 区间写清来源，没有官方来源的标注。
3. X：近一年同类高互动帖子的形式：时长、横竖屏、字幕、开头几秒、正文结构、是否串成 thread、是否带链接；中文圈博主的有效做法单独写。
4. 要不要剪 30–60 秒的短版，给出依据。
结构：一、结论；二、YouTube 爆款样本表；三、普通样本表；四、官方说明要点；五、X 的形式与样本；六、短版建议；七、方法与局限。
```

## 三、选题角度（同类产品与观众质疑）

```
你的任务：调研 <同类话题> 在中文网（B站、知乎、小红书、公众号、即刻、少数派）和英文网（YouTube、X、Reddit、Hacker News）上，哪些切入角度最火、观众最关心什么、最怀疑什么。
1. 同类和相近对象至少包括：<官方同类功能、开源竞品、热门叫法>。以近一年为主。
2. 统计各角度的热度：省钱、提速、拟人整活、对比测评、实战做出东西、新手一键安装、反常识。每个角度 2–4 条代表样本（链接、标题、数据、日期）。
3. 看高赞评论、弹幕和讨论帖，整理观众最关心的问题和最常见的质疑，每条附出处。
4. 给 3–5 个选题角度，每个配 2–3 个标题候选和一句话封面描述，写明依据；再列要避开的雷。
结构：一、结论；二、各角度热度与样本；三、观众关心与质疑；四、推荐选题与标题候选；五、要避开的雷；六、方法与局限。
```

## 四、私域

```
你的任务：调研怎样在不违规、不被限流的前提下，把 B站 / YouTube / X 的观众转进 <私域入口>，并给出这期能直接用的做法。
1. 规则原文：B站（社区公约、创作者规范、站外引流公告或处罚案例）、YouTube（外部链接、垃圾内容、误导性元数据）、X（平台操纵与垃圾信息）。重点：画面放群号或二维码、口播群号、简介、置顶评论、动态、私信自动回复、站内粉丝群，各自允不允许、有什么风险。查不到原文的写「未验证」，不要把传言写成规则。
2. 中文创作者引流到 QQ 群 / 微信群的常见做法和效果：钩子、位置、怎么说不像硬广；开源项目从 README 引流到群的做法。有数据写数据和来源，没有的写明是经验做法。
3. 结合本期给出可执行的漏斗：片内哪几个时点、什么话术；简介和置顶评论模板；群里准备什么；YouTube 和 X 怎么导；要避免什么。
结构：一、结论（按效果和风险排序）；二、各平台规则要点；三、常见做法与效果；四、本期漏斗方案（含话术和模板）；五、要避免的做法；六、方法与局限。
```

## 五、画师（Codex）

出图都交给 Codex 方。建助手时传 `target: "codex-desktop"`、`lifetime: "persistent"`（画到一半断了能接着画，之后还能追加）；指定 model 就把 effort 一起传。2026-11-10 那次一位画师一轮交了 15 张：大肥鱼设定图 1、大肥鱼动作 6、Claude 娘 2、GPT 龙娘 2、场景 2（梗图、四条大肥鱼坐一排工位）、横竖封面 2。

```
你是画师。用你内置的图像生成（image_gen）给 B 站视频「<片名>」画素材，不用 API。博主是咸鱼凌生，画风统一成频道的 Q 版贴纸：深海军蓝粗描边、平涂、少量网点，干净可爱。
角色身份严格照参考图：<角色 = 出处，参考图路径>。先画一张设定图（正面全身 + 几个表情），之后每张都引用它锁定形象。工牌这类地方留空，不写字。
清单（文件名｜内容｜背景）：
- <fish_work.png>｜<坐在工位上用笔记本打字>｜绿幕
- <scene_office.png>｜<四条大肥鱼坐一排工位，Claude 娘拿着夹板巡视>｜不透明 16:9
- <cover.png>｜横版封面 16:9：大字「<大字>」，上方小字「<小字>」，<角色和构图>｜不透明
- <cover_short.png>｜竖版封面 9:16：<文字和构图>｜不透明
要抠像的画纯绿 #00FF00 背景，发丝和缝隙不要彩边。封面文字逐字照写，不加别的字，四边留 5% 安全边距。不用红色圆盘配放射光芒，爆发感用漫画集中线。
每张画完立刻存到 <作品目录>\art\raw\，用 report_parent 报一句进度；全部画完用 report_parent(final: true) 交清单（完整路径｜像素｜背景）和每张的目视检查结果。不需要做像素后处理。
```

收图：

- 交回先看大图，核对角色身份、动作和封面上的每个字。要改的给同一个名字发「<文件名> 重画：<改哪里>」，已经采用的写明不再重画。
- 一轮停在中途没交 final，或者显示 `reconnecting`、报 `codex-native-rpc-unavailable`，任务和落盘一般不受影响：先看 `art/raw/` 和 `<用户目录>\.codex\generated_images\<会话id>\`，再给同一个名字发「剩下哪几张接着画」，不新建替代任务。
- 它为像素后处理来问时答「不需要」，抠像和改尺寸在本地做。

## 六、流量密码巡检（例行，派 DSH）

每三天一次，Claude 桌面版的定时任务「流量巡检 · 每三天」会照这一节自动派；新一期开工时上次巡检已经超过三天，就手动派一次。用 `futureaide_run_agent`，名字用「流量巡检」，`lifetime: "persistent"`（方便事后查过程）。尖括号换成实际值。

```
你是调查员，做一次 AI 领域的「流量密码」巡检。背景：博主「咸鱼凌生」的频道（B站为主，mid 307427146；YouTube、X 账号 XiaYuLS，只做中文），定位「让普通人，用上前沿生产力」，二次元 AI 娘风格，做 AI 工具教程，也可以做科普、测评、整活。今天是 <日期>。
先读 <工作区>\docs\grill\总览\调研\流量密码\流量密码速查.md 和上一份简报（同目录里日期最新的那份），知道上次的结论。
1. 跑脚本（脚本在 <skill 目录>\scripts\，数据都输出到 <工作区>\docs\grill\总览\调研\流量密码\数据\<日期>\）：
   python bili.py --out <数据目录> hotword
   python bili.py --out <数据目录> sample --kw <AI 关键词 12–15 个，比如 ChatGPT、Claude、DeepSeek、豆包、Gemini、Codex、Cursor、AI 教程、AI 工具、AI 科普、大模型、智能体、AI 视频、AI 绘画，再加速查里记着的当下热梗> --since <30 天前的日期>
   python douyin.py --out <数据目录> hot
   python yt.py --out <数据目录> search --kw <中文词 5 个> --kw <英文词 5 个> --when month --sort views --subs 30
   B 站接口被限流（HTTP 412）就停下等，不换身份重试；抖音热榜拿不到就用浏览器打开 https://www.douyin.com/hot 看。
2. 抖音补充：用浏览器看抖音热榜和公开能看的 AI 相关话题页、新榜或飞瓜这类榜单的公开页，记 AI 相关的爆款（标题、点赞、日期、链接）。不登录账号、不破解签名，拿不到的写「未验证」。
3. 判读：爆款看播放远超粉丝（B站）或观看远超订阅（YouTube）的；归纳题材、标题公式、时长、形式（科普、教程、测评、整活、新闻），这一个月新冒头的梗和叫法，和速查比什么在升、什么在退。赞、藏接近播放一半的这类异常样本剔除，不当证据。
4. 产出：
   - 写 <工作区>\docs\grill\总览\调研\流量密码\<日期>.md：一、这次的流量密码（5–8 条，按对本频道的可用程度排序，每条附样本链接和数字）；二、新冒头的梗和叫法（各附 2–3 条样本）；三、B站、抖音、YouTube 各自的爆款表（各 10 条以内）；四、给咸鱼凌生的选题建议 3–5 个（标题候选、封面一句话、长片还是短片；标题要有冲击力、有记忆点，让人一眼就想点进去，可以玩梗、可以来点地狱笑话式的幽默，比如「Claude：懒鱼！Go to Work！」这种；不靠堆感叹号，数字照实、不承诺做不到的效果）；五、和上次比的变化；六、未验证和失败的路径。
   - 更新 流量密码速查.md：只留现在仍有效的结论，每条写最近一次确认的日期；过时的移到文末「已过时」，写明哪次巡检判断过时的。没有这个文件就新建。
规矩：每条事实标来源（BV 号、链接或数据文件名），不编数字、不把估算写成事实；只写上面这几个文件和数据目录，不改别的文件。做完用 report_parent(final: true) 交：五条以内的要点 + 简报路径 + 未验证项。
```

验收：先看速查的改动是不是只增删了该动的条目；再抽两三条爆款，用数据文件或打开链接核对数字。

## 失败了怎么续

2026-11-10 那次，「YouTube 与 X」那位跑了一个多小时后执行失败，报告没写出来，但它抓的数据都留在临时目录里。没有重派新任务，而是给同一个名字发一句：「上一轮失败了，数据在 <目录>，不要重新大范围抓取，就用这些数据把报告写完，写完把临时目录移到 clean」。半小时内交回了完整报告。所以派单里最好写明临时文件放哪（放作品目录下或 `clean/`，别放项目根目录），失败时才有东西可续。

## 验收

- 报告到了先看文件，不只看摘要。
- 抽查：爆款表里挑两三条用 `bili.py` 或浏览器核对播放和粉丝；规则条款打开原文页核对关键句。
- 调查员之间结论冲突时，以有原始数据、样本更大的一方为准，在调研结论里写明分歧。
- 用完可以按名字删除（`futureaide_delete_agent`）。删除会清掉助手自己的会话记录，报告文件不受影响；会话记录是唯一的过程留底，要不要删由用户定，默认留着。
