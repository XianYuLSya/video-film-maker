# 私域引流：规则与模板

规则原文 2026-11-10 抓取（DSH 调查员整理，主对话抽查过 B 站条款）。平台规则会改，跨月使用前重新打开下面的链接核对。

## 一句话

视频负责「这东西真能用」，简介和置顶评论负责「出问题去哪问」，群负责「装得上、用得久」。钩子用**答疑、报错清单、版本通知**；不用**免费领、内测名额、福利、抽奖**。

## 各平台规则要点

### B 站（约束最多）

- 《社区公约》违规推广（<https://member.bilibili.com/studio/convention/content?index=2-9&navhide=1>）：点名「发布可能引起争议或损害用户利益的链接、二维码（包括关注导流、营销引流、交易转化等用途的网盘链接、二维码等）」；并对「诱导用户至第三方平台进行注册、关注、交易、消费……（如包含第三方平台链接、二维码、账号、标识等信息）」采取删除下线、限制传播。QQ 群号属于第三方平台账号，判定看是不是营销诱导、会不会损害用户利益，所以「开源免费工具 + 答疑」风险低，「进群领资料」风险高。
- 同页垃圾信息条款：禁止恶意使用弹幕、评论、标签、私信，发布重复或无关信息。弹幕刷群号、去别人评论区贴群号、私信群发都落在这条上。
- 违背创作公平（<https://member.bilibili.com/studio/convention/content?index=2-7&navhide=1>）：「利用奖励与用户直接交易，获取内容数据」，例如「关注就送 XX」「三连抽奖」。拿进群资格换三连属于这种形状。
- 处置手段（<https://member.bilibili.com/studio/convention/content?index=1-2&navhide=1>）：限制传播、删除、折叠；账号可被限制动态推送、清除违规新增关注；小黑屋封禁 7 天、15 天到永久（<https://www.bilibili.com/blackboard/blackroomrule.html>）。
- 投稿规范（<https://member.bilibili.com/studio/convention/content?index=3-5&navhide=1>）：含商品或服务购买推荐、或链接分享的内容，添加【内容含营销信息】。
- 2023-11-07《关于违规推广行为的治理公告》点名「未经平台合规商业渠道导流站外联系方式、二维码、小程序码、网址链接、红包口令」。原文页没取到，转引 <https://www.chinaz.com/2023/1107/1573312.shtml>。

### YouTube（基本不限制）

- 外链政策（<https://support.google.com/youtube/answer/9054257?hl=en>）：只禁止指向违规内容的链接；画面里显示网址、口播让观众去别的网站、置顶评论都算「链接」，指向内容合规就没问题。注意「部分链接可能不可点击」，可疑链接可能被移除，所以仓库名或群号要同时写成纯文字。
- 垃圾内容政策（<https://support.google.com/youtube/answer/2801973?hl=en>）：「唯一目的就是把人导走」的内容才算 off-platform diversion；请观众点赞、评论、订阅是允许的；标题封面承诺了却不兑现算恶意标题党。

### X

- Authenticity 政策（<https://help.x.com/en/rules-and-policies/authenticity>，直连 403，取自 web.archive.org 2026-01-02 快照）：禁止批量、重复、无关、未经请求的回复、提及和私信；禁止蹭热门标签导流；禁止反复发只有链接没有文字的帖子。bio 和钉选帖里放一次链接正常。

## 位置和做法

| 位置 | 做法 | 风险 |
|---|---|---|
| 片中 | 片尾口播 + 画面纯文字群号，停 2 秒以上；中段讲到容易卡住的步骤时说「先看文档那张表，还不行进群问」 | 低；不放二维码，不说「扫码」「领」 |
| 简介 | 两三行：工具或资料的正式入口（官网、GitHub）+ 群号 + 一句「装不上、报错来群里问」 | 低；含链接时考虑加【内容含营销信息】 |
| 置顶评论 | 写成「本期常见问题」：三四条最容易卡的点和处理办法，最后一句「表里没有的发群里」 | 低；发布后 10 分钟内自己置顶 |
| 动态 / 专栏 | 发布后 24 小时内发「安装避坑清单」，群号放文末 | 低 |
| 弹幕、别人的评论区、私信群发 | 不做 | 高，直接落在垃圾信息条款上 |
| YouTube 简介和置顶评论 | 同 B 站，入口链接和纯文字都写 | 低 |
| X | bio 放正式入口；发布当天一条主帖并钉选，配 2–3 条内容不同的帖（原理、演示、答疑） | 低；不批量回复贴链接、不带无关热门标签 |

## 话术红线

照念前自查，出现就改：免费领、送、进群才有、名额有限、抽奖、扫码、关注/三连后进群。

## 模板

把尖括号换成本期内容。

**片尾口播（约 8 秒）**

> <工具>是开源的，<入口说法，比如「GitHub 搜 某某/某某」>。装的时候报错、或者用不明白，来 QQ 群 <群号>，我常在群里回。群号在简介和置顶评论里。

**B 站简介**

```
<一句话说清这期讲的东西>（<开源 / 免费 / 平台限制等关键事实>）
<正式入口>：<网址或「GitHub 搜 xxx」>
装不上、报错、用不明白 → QQ 群 <群号>，我常在里面回
```

**置顶评论**

```
【本期常见问题】
1. <最容易卡的前提条件>
2. <第二个常见坑和处理办法>
3. <验证成功的方法>
4. <一个高频报错 → 处理办法>
上面这些 <文档名> 里都有。没写到的，发 QQ 群 <群号>，带上截图和报错原文。
```

**X 主帖**

```
<一句话：这个东西能帮你做什么>
<平台 / 许可 / 入口链接>
中文答疑在 QQ 群 <群号>。
```

## 群里先准备好

| 项 | 内容 |
|---|---|
| 群公告第一条 | 正式入口 + 三四条前提条件 + 报错自查表在哪 |
| 群文件 | 安装自查清单；提问模板（报错原文、截图、系统版本、装在哪） |
| 置顶消息 | 「提问请带：报错原文 + 截图 + 你装在哪」 |
| 版本通知 | 每次更新发更新记录摘要，这是群长期留人的理由 |
| 群规 | 禁广告、禁私加推销、禁发其他群二维码；群一旦变成卖东西的地方，视频里的群号就从答疑变成交易导流 |

## 发布后 72 小时

| 时间 | 动作 |
|---|---|
| 发布时 | 简介按模板；10 分钟内发置顶评论并置顶 |
| 发布当天 | 一条短动态：本期最关键的一两步 + 「群号在置顶评论」 |
| 2 小时后 | 看评论区，重复的问题统一回「看置顶评论」，把新问题补进置顶评论，一次改好 |
| 24 小时 | 发避坑清单专栏或动态，群公告更新到最新 |
| 72 小时 | 汇总群里最常见的五个报错，补进文档的常见问题表，在群里说一声 |

## 未验证

B 站放群号的具体处罚案例；站内粉丝群、应援团的开通门槛和能否发外部群号；私信自动回复的门槛；「频繁改简介会限流」的说法；任何加群率、转化率数据（没找到可信来源，不要编百分比）。
