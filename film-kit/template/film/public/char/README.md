# 占位角色

这里是一套**占位图**：12 个姿势 × 3 帧抖动（`<姿势>_c0/c1/c2.png`），画的是一个写着「占位角色」的中性小人，只为让模板拿到手就能渲。`manifest.json` 记每个姿势的尺寸。

- 做自己的片子时，把这些图换成你自己的角色：同名、透明底 PNG、三帧轻微抖动，代码不用改。姿势表在 `film\src\kit\overlay.tsx` 的 `POSES`。
- 占位图由 `tools\make_placeholder_chars.py` 生成，随本项目一起授权（许可证见仓库根目录）。
- **仓库不带任何频道的角色形象。** 咸鱼凌生频道片子里出现的吉祥物「小咸鱼」是频道自己的形象，不在本项目里，也不在本项目许可证的授权范围内，请不要从频道的视频里截取或仿制它来用。
