# 致谢与来源

这套镜头包（`cine\` 目录下的全部代码、`scripts\capture.mjs`、片场 `tools\` 下的 `look_check.py`、`sheet.py`、`beat_probe.py`）是我们自己写的，没有拷贝任何第三方源文件。

做的过程中，我们向开源项目 **video-shotcraft**（Apache-2.0 许可）学了方法和写文档的格式。照实记在这里：学了什么、哪几处实现和它同构、哪些是我们自己的。开源发布时这一页随代码一起发。

## 学到的方法

| 学了什么 | 用在哪 |
|---|---|
| 复刻产品界面的镜头，素材必须从真实页面截：整页高倍纹理、空底板、元素抠图、坐标表，四样一起出 | `scripts\capture.mjs` 的产出结构 |
| 三维里界面文字发糊，根因在栅格化路径：放大量要走布局级的 `zoom`，不能写进 `transform` 的 `scale` | `Screen.tsx` |
| 文字只有两种状态：当纹理（虚、暗，不要求读）或要读（够大、够清楚），没有中间态 | `Statement` / `Label` 的分工；手册的自检问题 |
| 镜头稳、不加手持抖动；光效克制，一个镜头最多给主角一次；开场只给一个主角 | 机位预设不提供抖动；`sheen` 的用法；范例片的开场 |
| 无口播的片子按音乐的拍子排时间；全屏级的冲击全片不超过三处 | `beat.ts`、`Reel` 的规矩 |
| 音效是「时刻 + 类别 + 音量」的声明式清单，和画面用同一套时间；最响的那一下对在动作上 | `sfx.ts`（事件格式沿用片场自己的 `kit\sfx.tsx`） |
| 镜头卡的写法：这个镜头是什么、什么时候用、参数表、已知的坑、自检问题；准则写成「规则 + 判例 + 自检」 | `手册.md` 的卡片格式 |
| 几种镜头的想法：贴面掠过时元素悬空再落位、行从空中嵌入列表、字的笔画当窗口透出界面再冲进去、扫描线逐个框住元素、界面里的小徽标翻成应用图标 | `Float`、`TypeWindow`、`Scan`、`Lockup` 各自要解决的问题 |

范例片（FAswitch 品牌片）的分镜、拍号和文案，沿用的是我们另一位设计师用 video-shotcraft 做出、并被用户认可的那一版的结构；它在暗色界面上把「悬浮元素的投影」换成「虚线空槽 + 落地缝」的办法，我们也采用了。

## 实现上同构的地方

下面几处，问题只有一种自然的解法，或者我们有意沿用了同一个办法。代码是自己写的，结构相近：

1. **`Screen.tsx` 的三维变换**。父层 `perspective = 透视距离 × 放大倍数`；屏那一层设 `zoom`，`transform` 写成「平移（落点 ÷ 放大倍数 − 看的点）→ rotateY → rotateX → rotateZ」，旋转中心在看的那一点。这和 video-shotcraft `PageCam` 的三维模式是同一个算式（要让三维里的字清楚，放大只能这么放；旋转顺序定了，算式也就定了）。我们加的是：看的点可以落在画面任意位置、和这套变换逐项对应的投影计算（`cam.ts` 的 `project`，景深和各项检查靠它）。
2. **景深用「同一个画面多渲几遍，模糊的那几遍加遮罩盖在清晰版上」**。video-shotcraft 的示例里用过同一类做法（一遍模糊、一张椭圆遮罩）。我们的遮罩是按机位算出来的焦点带（线性渐变、两档模糊、近处更虚），焦点跟着指定的元素走。
3. **`TypeWindow` 冲进字里的那一段**。放大倍数按指数走、冲入点逐渐挪到画面中心、冲到头时字里的界面接管全屏：这个三段式和 video-shotcraft 的 text-as-mask 镜头是同一个办法。字形的做法不同：我们用页面里的 SVG 剪裁路径配自带字体，洞口加内阴影和高光；它用 SVG 图片遮罩配系统字体和外投影。
4. **`Statement` 的「浮上来」出场**。位移、模糊、透明度共用同一个进度。这是很常见的写法，video-shotcraft 的 blur-slide 镜头也是这样。
5. **`Float` 的下落**。加速下落加软着陆的那条曲线是 `cubic-bezier(0.5, 0.05, 0.6, 1)`，和那位设计师的版本用的数值相同。
6. **`capture.mjs` 的抠图**。「把其余部分设成不可见、用透明底截图」是同一类做法。具体写法不同：我们只把根元素设成不可见、靠继承往下传，再把目标元素放开；把所有元素逐个设成不可见的写法，会让用 `<use>` 引用的图标抠出来是空的。
7. **`Label` 的样子**（22 像素等宽、大写、宽字距、编号用产品色）。照的是用户认可的那一版的观感。

## 我们自己的

机位写成「预设 + 看哪个元素 + 占多大 + 落在哪」和它的求解；投影几何和基于它的各项防呆；按深度算的景深带；屏的辉光和「屏把灯光告诉屏上的东西」；整块落位、让位离开；`Take` 标准镜头；`Pages` 的世界和视角；`Reel` 的转场接法；`Lockup` 的版式和时间；按拍取时间和片场流水线的对接；截图工具（不依赖浏览器自动化库，直接走调试协议；演示数据的小工具；可疑内容的自动标注）；三个审片工具。

## 素材

- 字体：片场自带的思源黑体、Inter、JetBrains Mono，都是 SIL OFL 许可，可以随工程分发。
- 配乐和音效文件**不随片场和这套镜头包分发**。代码里只有声音的类别名和「曲子的路径、拍长、起点」这样的配置项，各人放自己有权使用的文件。
- 陈列片用的示例界面（`cine-demo\web\index.html`）是我们自己写的虚构界面，数据全是编的。
