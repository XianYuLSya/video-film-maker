# 品牌片风格包 · 手册

`film\src\brand\` 是给**品牌片、logo 演绎、产品发布片头**用的一套画面语言。全部从 `brand\index.ts` 导入：

```tsx
import {Stage, Lanes, FishMark, EndFrame, faNight, faPaper, BE, DUR} from '../brand';
```

陈列片：合成 `BrandGallery`（2 分 05 秒，每个组件 4–6 秒，最后是 19.4 秒的 FAswitch 品牌片样稿）。
抽帧：在 `template\` 下 `.\film.cmd stills BrandGallery 21.6 60 113.1`。每段起点见文末「陈列片目录」。

---

## 1. 什么时候用它，什么时候用 blocks\

| | `blocks\`（教程积木库） | `brand\`（本风格包） |
|---|---|---|
| 片子 | 教程、讲解、带口播的长片 | 15–30 秒品牌片、logo 演绎、发布片头、片尾品牌卡 |
| 底 | 奶油纸底（外壳画） | 自己铺：深色或浅色「高级底」+ 光斑 + 暗角 + 颗粒（`Stage`） |
| 线 | 粗描边、白卡、贴纸 | 1–1.5px 细线；徽标线按真徽标比例 |
| 运动 | 弹簧弹出，热闹 | 不弹；快起慢停（`BE.out`），一次只动一样东西 |
| 字 | 得意黑、粗、多 | Inter / 思源黑，大字 300 字重，一屏一句 |
| 吉祥物 | 小咸鱼 | **没有**。品牌的形象只有它的徽标 |

**一部片子里不要混用两套**。教程片片尾要一张品牌卡时，那一幕整幕用 brand（`bare: true`），别把 brand 的组件塞进纸底场景里。

## 2. 通则（违反任何一条都会显廉价）

**一屏放多少**
- 一屏只有**一个主体**：一句话，或一个徽标，或一组（≤ 6 个）同类元素。其他都是「底下的秩序」（网格、细线），比主体弱一大截。
- 留白至少占画面一半。主体宽度一般不超过画面 60%。

**字**
- 中文大字 `TYPE.zhTitle`（76px / 300 字重 / 字距 0.04em）；英文大字 `TYPE.title`（88px / 300 / -0.02em）或 `TYPE.hero`（132px）。
- 大字永远 200–400 字重。600 以上只给字标（logo 的文字部分），而且字标默认也只用 500。
- 小字（注释、角标）用 `Kicker`：等宽大写 22px、字距 0.18em、`ink3` 颜色。正文最小 22px。
- 一屏最多两种字号（主体 + 小字），最多一种字体家族（Inter + 思源黑算一家）。

**颜色**
- 一屏 = 底色 + 墨色的三档（`ink` / `ink2` / `ink3`）+ 一个强调色。强调色只点 1–2 处（一个点、一条线、两个字），面积 ≤ 5%。
- 不用彩虹渐变、霓虹、多彩图标。不用纯黑纯白（`makeTheme` 已经帮你避开）。
- 不用厚重投影。层次靠「亮一档的面 + 1px 细线」，不是靠阴影。

**运动**
- 入场一律 `BE.out`，位移 `BE.move`，透明度 `BE.soft`，归位 `BE.settle`，退场 `BE.in`（退场比入场短）。**不用线性**（只有机械扫过的东西可以）。
- 时长：小东西 0.45–0.8s（`DUR.short` / `DUR.base`），大动作 1–1.6s（`DUR.long`），徽标描线 2–2.4s（`DUR.slow`），镜头推拉 ≥ 4s。
- **一次只动一样东西**。多个同类元素依次出：逐字 0.06s、逐条 0.08s、逐块 0.12s（`STAGGER`），总错开不超过 0.3–0.5s；跟着配乐时可以「一拍一个」。
- 一个主动作 + 最多一个辅助动作（比如：线在归位 + 镜头极慢地推）。不要同时缩放、旋转、位移、变色。
- 过冲：全片 0–1 次，只用 `BE.lift`（约 3%），只给「徽标落定」那一下。光、颗粒、渐变永不过冲。
- 每个动作结束后留一口气（≥ 0.4s 什么都不新增）再开始下一个。片尾定格 ≥ 1.5s 完全不动（颗粒和光斑除外）。

**手机可读性（每一版都要过）**
- 这类片子大多在手机信息流里看，画面会缩到约 390px 宽（缩小 4.9 倍）。把关键帧缩到 390 宽拼在一起看一眼：主体认不认得出、字读不读得出。
- 由此倒推的下限：主词 ≥ 64px，注释 / 标语 ≥ 28px 且颜色至少 `ink2`（不用 `ink3` 写要读的字），主体的线在暗底上至少 2px、亮度 ≥ 60%。
- 克制 = 元素少，**不是**元素小、对比低。主体通常占满画幅，明暗对比要开。
- 拼图办法：`python -c` 用 PIL 把几张 PNG 缩到 390 宽横排（见 `美术方向\手机宽度对照_390px.png`）。

**不许做**
- 红色圆盘 + 放射光芒（频道禁忌）；卡通图标乱飞、贴纸、表情；文字弹跳、抖动、打字机音效。
- 所有东西一起进场；进场后原地晃个不停。
- 全屏大模糊来「做氛围」：氛围用 `Stage` 的光斑（径向渐变，不用滤镜）。

## 3. 时间参数约定

和积木库一样：所有组件吃成片秒数 `t`，`at` = 这个组件开始出场的时刻，`out` = 开始退场的时刻（不传就一直在）。
需要「先出现、再变化」的组件有两个时刻：`t0` = 出现，`at` = 开始变化（`Lanes`、`Arrange`）。
每个组件都有同名音效函数 `xxxSfx(props)`，返回 `Ev[]`，把它并进场景的 `sfx()`。

## 4. 组件

### 配色 `theme.ts`

```tsx
const th = makeTheme({mode: 'dark', accent: '#2B8A57'});                 // 深底，底色由主色微微染出
const th2 = makeTheme({mode: 'light', accent: '#3A5BD9', bg: '#F3F1EC'}); // 浅底，自己定底色
// 现成：THEMES.graphite（深）、THEMES.ivory（浅）；FAswitch：faNight、faPaper
```
字段：`bg bg2 surface ink ink2 ink3 line line2 accent accentInk accentSoft pool grain vignette`。
**颜色一律从 theme 取**，不要在场景里写十六进制。小工具：`mix(a, b, p)`、`alpha(hex, a)`。字体 `BF.sans / zh / serif / mono`，字号档 `TYPE`。

### 缓动 `motion.ts`

`BE.out / move / soft / settle / in / lift / sine`，`DUR.micro short base long slow cam`，`STAGGER.char word block`。
`prog(t, t0, dur, ease)` 进度 0..1；`tw(t, t0, dur, a, b)` 数值插值；`win(t, at, out)` 出现窗口；
`drift(t, amp, period)` 缓慢漂移；`hash(n)` 稳定伪随机；`beatAt(t0, beat, n)` 第 n 拍。

### 舞台 `Stage`

```tsx
<Stage t={t} theme={th} light={prog(t, t0, 2.4, BE.soft)}>…内容…</Stage>
```
一个场景只铺一个。`pools` 光斑（不传用默认两团，`[]` 关掉）、`light` 光斑亮度 0..1、`grain` / `vignette` 覆盖 theme 的颗粒和暗角（0 关）。
颗粒是 feTurbulence 半分辨率放大、每 1/24 秒换种子，确定性。

### 描线 `DrawPaths` / `smoothPath` / `polyPath`

```tsx
<DrawPaths t={t} at={t0 + 0.4} dur={2} viewBox="0 0 200 200" width={400}
  strokes={[{d: 'M100,22 A78,78 0 1,1 99.9,22', weight: 1.6}, {d: '…', weight: 0.8}]}
  color={th.ink} lineWidth={7} glow glint />
```
- 多段依次描，`weight` 决定每段分到的时长；也可以给每段自己的 `at` / `dur`。圆线头圆拐角。
- `glow`（true 或 0..1）：线下垫一层模糊的同色线，深底用；浅底别开。
- `glint`：描完后一道高光按描线顺序走一遍。全片最多一次。
- 自己描路径：`smoothPath([[x,y],…])` 过点出顺滑曲线；要尖角用 `polyPath`。
- 音效 `drawPathsSfx({at, dur, strokes, glint})`。

### 文字 `Reveal` / `Title` / `Kicker` / `revealEnd`

```tsx
<Title t={t} at={t0 + 0.4} kind="title" text={'Designed for\nthe long run.'} color={th.ink} />
<Title t={t} at={t0} kind="zhTitle" mode="chars" text="把复杂的事，*留给自己*。" color={th.ink} accent={th.accentInk} align="center" />
<Reveal t={t} at={t0} text="NORTHWIND" mode="track" size={120} weight={300} tracking="0.08em" color={th.ink} align="center" />
<Kicker t={t} at={t0} text="Chapter 02 · Workflow" theme={th} />
```
- `mode`：`mask`（默认，遮罩上滑，标题首选）、`chars`（逐字，≤ 14 字的短句）、`track`（字距收拢，字标和英文大字）、`fade`（副标题、小字）。
- `*包起来*` 的字用 `accent` 色；`mark={{at, color}}` 给强调字画一道荧光笔底衬（官网「各归各位」的写法）。
- 多行用 `\n`；`out` 退场；`revealEnd({...})` 算出场完成时刻，排后面的动作用。
- 音效 `revealSfx({at, mode})`（一声很轻的气流；不配打字声）。

### 标志锁定 `Lockup`，最终定格 `EndFrame`

```tsx
<Lockup t={t} at={t0} theme={th} mark={fishMarkFn()} markRatio={FISH_RATIO} markScale={1.4}
  name="FAswitch" tagline="账号、代理、时区，*各归各位*。" tagMark size={104} />

<EndFrame t={t} at={t0} theme={faPaper} mark={fishMarkFn({draw: false})} markRatio={FISH_RATIO} markScale={1.4}
  markFrom={{cx: 960, cy: 520, width: 580}} name="FAswitch" tagline="…" tagMark note="本机运行　·　互不串号" />
```
标语字号 = 0.42 × size（size 104 时 44px），底部小字 26px、`ink2`，都是按手机宽度倒推的。

- 比例全按字标字号 `size` 算死：图形高 = 1.05 × size（`markScale` 再乘）、间距 0.4 × size、安全留白 0.6 × size、标语在留白之外。`guides` 画出留白框。
- 顺序固定：图形 → 图形先让位（居中滑到左边，或 `markFrom` 从上一幕的位置缩放过来）→ 0.75 秒后字标遮罩升起 → 标语淡入 → 强调字底衬。字标永远不会和图形叠在一起。
- `nameDelay`（默认 1.8，图形要描线时留够）、`tagDelay`（默认 0.8）。
- `EndFrame` = `Stage` + 居中 lockup + 可选底部一行小字 `note`；`stage={false}` 时不自铺舞台。
- 图形函数 `MarkFn = ({t, at, height, color}) => ReactNode`，自己的品牌照 `fishMarkFn` 写一个。
- 音效 `lockupSfx` / `endFrameSfx`（同参数）。

### 构成元素 `Grid` / `Rule` / `Orbit` / `CornerMarks` / `Disc`

```tsx
<Grid t={t} at={t0} theme={th} box={{x: 160, y: 140, w: 1600, h: 800}} cols={8} rows={4} />   // dots 只画交点
<Rule t={t} at={t0} x={200} y={790} w={1520} theme={th} from="left" />
<Orbit t={t} at={t0} theme={th} radii={[170, 290, 410]} tilt={0.42} accent={1} />
<CornerMarks t={t} at={t0} box={{x: 560, y: 340, w: 800, h: 400}} theme={th} />
<Disc t={t} at={t0} cx={960} cy={520} r={240} color={mix(th.bg, th.ink, 0.11)} theme={th} halo={1.5} lift={{at: t0 + 2.6, amount: 0.05}} />
```
网格线从中间向两边展开；`Orbit` 同心不相交（「各自运行」）；`Disc`（`Disc.tsx`）是一块由虚到实升起的圆盘（月亮、光源）：受光渐变、边缘羽化、外圈淡光晕，`lift` 让它在主体落上去时再亮一点；可以做 `Iris` 的起点。

### 无序到有序 `Lanes` / `Arrange` / `Tile`

```tsx
<Lanes t={t} t0={t0 + 0.4} at={t0 + 4.71} theme={th} lanes={[{label: '账号', note: '各自登录'}, …]}
  box={{x: 300, y: 250, w: 1220, h: 560}} tangleBox={{x: -160, y: 250, w: 2240, h: 580}} depth={[1, 0.2, 0.62]}
  labelW={230} size={76} noteSize={38} lineWidth={2.2} stagger={0.6922} dur={1.5} />

<Arrange t={t} t0={t0} at={t0 + 1.8} theme={th} slots={gridSlots(6, 3, 340, 190)}
  items={names.map((n, i) => ({w: 340, h: 190, render: (s) => <Tile theme={th} title={n} note={`0${i + 1}`} placed={s.placed} />}))} />
```
- `Lanes`：几条线先缠在一起缓慢摆动（`t0` 出现），到 `at` 依次理顺成平行轨道，标签落到各自轨道左端，右端节点点亮强调色、`note` 浮出。「各归各位、互不串号」用它。`stagger` 可以直接给配乐一拍，一拍落一条。
  - `tangleBox`：缠绕时的区域，放开到比画幅还宽（如 `{x: -160, y: 250, w: 2240, h: 580}`），线会出画；`box`：理顺后的区域，占画面中间一大半。
  - `depth`：每条线缠绕时的远近 0..1（近 = 粗、亮、带模糊微光；远 = 细、暗、发虚），理顺后统一成 `lineWidth`。
  - `labels`：默认 `'land'`，缠绕时不出字、每条落位时标签才由虚到实升起；`'start'` 是一开始就挂在线上。
  - 字号：`size` 主词（品牌片 ≥ 64，FAswitch 用 76）、`noteSize` 注释（≥ 28，FAswitch 用 38）。
- `Arrange`：块先散落、歪斜、轻轻漂，再按槽位依次归位；空槽位先以细框出现，块落进去时细框亮一下。`rowSlots` / `gridSlots` 算槽位。
- 乱的那一段要短（1–3 秒）、要慢；归位要干脆、不弹。
- 音效 `lanesSfx({t0, at, stagger, dur, n})` / `arrangeSfx({t0, at, n})`（每条落位一声 `lockq`）。

### 光与镜头 `Camera` + `Depth` / `Focus` / `SweepText` / `LightSweep` / `Iris`

```tsx
<Camera t={t} t0={t0} t1={t0 + 5.5} from={{s: 1}} to={{s: 1.045, y: -6}}>
  <Depth d={0.4}>远景</Depth><Depth d={1}>主体</Depth><Depth d={2}>前景小点</Depth>
</Camera>
<Focus t={t} at={t0 + 0.3}>…由虚到实的主体…</Focus>
<SweepText t={t} at={t0 + 0.8} text="Northwind" size={150} weight={500} color={…} />
<LightSweep t={t} at={t0 + 2.4} theme={th} />
<Iris t={t} at={t0 + 3} cx={960} cy={520} r0={232}>…下一幕（自带 Stage）…</Iris>
```
- 镜头：推 3–6%、平移 ≤ 40px、时长 ≥ 4s，几乎感觉不到才对。
- `Focus` 只包主体（不包整个场景），聚焦完自动去掉滤镜。
- 光扫整片最多两次。`Iris` 的圆心放在上一幕的圆形物体上（月亮、节点），转场是「顺着形状走」。
- 音效 `focusSfx` / `sweepTextSfx` / `lightSweepSfx` / `irisSfx`。

### FAswitch 素材 `faswitch.tsx`

`FA`（官网色值）、`faNight` / `faPaper`（两套配色）、`FishMark`（照 `sleepy-fish-mark-1024.png` 逐点描的徽标，线宽 = 原图比例）、
`fishMarkFn({draw})`（给 Lockup 用）、`FISH_RATIO`、`FISH_PATHS`、`fishMarkSfx`。
**徽标只用 `FishMark`**，不要用 `ui\fa.tsx` 里的 `SleepyFish`（那是教程界面里的简化小图标，不像真徽标）。
`FishMark` 的 Z 会一直极慢地上下浮（官网首页也是这么浮的），这是唯一允许在定格里动的东西。

## 5. 一部 15–20 秒品牌片怎么搭（骨架）

**稿子**（`script.json`）：一个垫片撑画面，一句口播收尾。垫片时长 = 配乐整小节。

```json
{
 "chapters": [{"id": "film", "zh": "品牌片"}],
 "items": [
  {"ch": "film", "sting": "open", "dur": 13.95},
  {"ch": "film", "id": "tag", "zh": "FAswitch，账号、代理、时区，各归各位。"}
 ]
}
```
`film.json`：`"stings": false`（只关通用片头片尾）；念法表 `["FAswitch", "F A switch"]`；`pacing` 的 `tail` 调到让片尾停够 1–1.5 秒；
配乐登记自定义曲子并给拍长，就能按小节对齐（例：`"tracks": {"geazy": {"file": "g-eazy-nba-type.mp3", "beat": 0.6922, "phase": 0.0}}`，段落 `{"from": "sting:open", "track": "geazy", "bar": 0}`）。

**场景**（`scenes\Brand.tsx`）：整幕 `bare: true`，底由 `Stage` 自己铺；时间全部从垫片起点按拍子取。

```tsx
import React from 'react';
import {AbsoluteFill} from 'remotion';
import {E, sting} from '../lib/time';
import type {Scene} from './common';
import {BE, Camera, Depth, Disc, EndFrame, FA, FISH_RATIO, FishMark, Iris, Lanes, Stage, faNight, faPaper,
  fishMarkFn, fishMarkSfx, irisSfx, lanesSfx, endFrameSfx, discSfx, mix, prog} from '../brand';

const BEAT = 0.6922;          // 这首曲子的一拍
const BAR = BEAT * 4;         // 一小节
const t0 = () => sting('open').start;
const bar = (n: number) => t0() + n * BAR;  // 第 n 小节的第一拍（成片秒数）

const C: React.FC<{t: number}> = ({t}) => (
  <AbsoluteFill style={{background: '#000'}}>
    {t < bar(5) + 0.05 && (
      <Stage t={t} theme={faNight} light={prog(t, t0(), 2.4, BE.soft)}>
        {/* 幕一、二：Lanes；幕三：Disc + FishMark —— 具体见 BrandGallery.tsx 的 FaBrandSample */}
      </Stage>
    )}
    <Iris t={t} at={bar(5) - 0.95} cx={960} cy={520} r0={240}>
      <EndFrame t={t} at={bar(5)} theme={faPaper} … />
    </Iris>
  </AbsoluteFill>
);

export const BrandScene: Scene = {
  id: 'brand',
  range: () => [0, E('tag') + 3] as const,   // 画到片尾，宁可多不可少
  C,
  sfx: () => [...lanesSfx({…}), ...fishMarkSfx({…}), ...irisSfx({…}), ...endFrameSfx({…})],
  bare: true,
};
```

**对拍子的规矩**
- 「落位」「切换」这种有分量的瞬间放在小节第一拍（`bar(n)`），次要的放在拍上（`bar(n) + k * BEAT`）。
- 动作要在拍子上**到达**，不是在拍子上开始：`Lanes` 的 `at` = 落位拍 − `dur × 0.55`；`Iris` 的 `at` = 拍子 − `dur`。
- 口播从最后一个大拍开始（`sting` 时长就是这样定的），定格在口播念完后再停 ≥ 1.5 秒。
- 结尾那句的字幕不烧进画面（bare）；定格上已经有标语，不必再放字幕。

完整可抄的范例就是 `BrandGallery.tsx` 里的 `FaBrandSample`（7 小节 19.38 秒），分镜在频道自己的工程 `<工作区>\work\FAswitch品牌动画\美术方向.md`（不随片场分发）。

## 6. 渲染耗时

- 抽静帧：陈列片每批 12–24 张（含打包）27–45 秒，约 1–1.5 秒一张，和调研报告实测的「每张 1.1–2.4 秒，开销在新建页面，不在画面复杂度」一致。
- 逐帧渲染：调研报告在本机实测全屏 `blur`、`feTurbulence`、`drop-shadow` 都在基线 80–85 ms/帧的 ±5% 内。本包用到的颗粒（半分辨率 feTurbulence）、光斑（径向渐变，无滤镜）、描线微光（小面积 feGaussianBlur）都是这几类。**本包自己的逐帧耗时没有单独测**（CLI 渲染测试那次卡住被我停了），正式渲染时看 `render` 日志里的速度。
- 真正会慢的：`@remotion/motion-blur`（约 7 倍，本包不用）；`Focus` 包住很大的东西时理论上更慢，只包主体。
