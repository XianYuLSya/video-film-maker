# 画面积木手册

写给做片子的助手看。片子的画面全部用这里的积木拼：**挑积木 → 填内容 → 对上时间 → 接音效**。不要自己从零写版式、配色、字号和出场动画，积木已经替你管好了文字不溢出、不压字幕、不出安全区。

- 代码在 `src/blocks/`，场景里一律 `import {...} from '../blocks'`。
- 看效果：陈列片 `Gallery`（横屏 180 秒）和 `GalleryV`（竖屏 114 秒），下表「陈列秒数」就是在陈列片里第几秒能看到。出图：在作品根目录（有 `film.cmd` 的那层）跑 `.ilm.cmd stills Gallery 23 24.5`，竖屏换成 `GalleryV`。
- 一部完整的范文：模板自带的示范片，场景在 `src/scenes/`（Hook / Script / Sync / Run / End），竖屏短版在 `src/short/Short.tsx`。写新片先照着它抄，见本手册最后一节。
- 陈列片源码 `blocks/Gallery.tsx` 本身就是一份完整的用法样例，拿不准时照着抄。

## 通用规则（每块积木都一样）

**时间参数**

- `t`：成片秒数，场景组件收到什么就传什么。
- `t0`：整块积木出现的时刻。`t1`：退场时刻（淡出 0.3 秒），不给就一直在，直到场景结束。
- 条目型数据（卡、步骤、行、节点、消息…）每条带自己的 `at`：念到它的那一刻。
- 时间一律从时间表取：`S('句id')` 是句子开始，`E('句id')` 是句子结束，`C('句id','标记')` 是念到 `{标记}` 的瞬间。**积木本身不读时间表，你算好传进去。**

**音效**：每块积木都有一个同名小写加 `Sfx` 的函数（`CardRow` → `cardRowSfx`），参数和积木的 props 一样（不含 `t`），返回 `Ev[]`，时间点已经和动画对齐。做法：把 props 写成一个函数，组件和音效共用它。

```tsx
import {CardRow, cardRowSfx, ChapterTag} from '../blocks';
import {C, S, E} from '../lib/time';

const cards = () => ({
  t0: S('p3'),
  t1: E('p5'),
  title: '三种付款方式',
  items: [
    {at: C('p3', 'card'), title: '国内信用卡', desc: '最省事，部分卡会被拒', icon: 'card', badge: '推荐'},
    {at: C('p4', 'virtual'), title: '虚拟卡', desc: '成功率高，要先充值', icon: 'shieldCheck', tone: 'mint' as const},
    {at: C('p5', 'agent'), title: '找人代充', desc: '便宜，但有封号风险', icon: 'alert', tone: 'coral' as const, mark: 'no' as const},
  ],
});

const Pay: React.FC<{t: number}> = ({t}) => (
  <>
    <ChapterTag t={t} t0={S('p1')} text="第二步：绑卡付款" icon="card" />
    <CardRow t={t} {...cards()} />
  </>
);
const sfx = (): Ev[] => [...cardRowSfx(cards())];
```

**位置**：整屏积木默认就摆在安全区里，不用给坐标。能分半屏的积木有 `slot: 'left' | 'center' | 'right'`（左半、居中、右半）。竖屏统一加 `vertical`（画布 1080×1920）。

**文字**：

- 什么长度都能填，积木会自己「先轻缩 → 换行 → 缩到下限 → 截断」，不会出框、压边、互相盖住。被截断时浏览器控制台会有 `[积木] … 放不下，已截断` 的警告，看到就把字改短。
- 用 `*星号*` 包住的字会变成强调色（珊瑚橙），如 `'绑卡总是*被拒*？'`。等宽字体（终端）不识别星号。
- 写短一点永远更好看：标题 ≤12 字，卡片标题 ≤8 字，说明 ≤20 字，步骤 ≤12 字。

**图标**：`icon` 填 `ui/icons.tsx` 里的名字：check、x、alert、bolt、chat、clock、lock、key、user、users、star、heart、search、settings、globe、monitor、phone、mail、card、shield、shieldCheck、download、folder、file、fileText、code、route、link、play、sparkles、thumb、qq、calendar、bookOpen、clipboard、ban、cloud、server、camera、music、gamepad、bell、help、info、pin、layers、sliders、trash、send、copy、refresh、upgrade、languages、mouse、plug、briefcase、presentation、activity、chart、edit、pencil、inbox、archive、logIn、logout、idCard、eraser、swap、menu、more、plus、minus、arrowRight、arrowLeft、arrowUp、chevRight、chevDown。写错名字只会画空白。

**颜色 tone**：`'coral'` 珊瑚橙＝强调、警告、错；`'mint'` 薄荷绿＝对、完成、通过；`'sun'` 黄＝荧光提示、当前；`'sky'` 蓝＝中性信息、链接、按钮；`'ink'` 墨蓝＝默认、深色标签。

## 整屏版式

### Hook 开场钩子

**什么时候用**：片子第一句。观众的痛点一句句砸出来（2–4 句），最后落到片名或一句承诺。
**别用**：痛点超过 4 句（多的会被丢掉）；正文中间。

| prop | 类型 | 默认 | 含义 |
|---|---|---|---|
| t0 / t1 | number | — | 出现 / 退场 |
| lines | `{at, text}[]` | — | 2–4 句痛点，每句 10 字左右，`*星号*` 标强调 |
| land | `{at, text, sub?}` | 无 | 落点：大字 + 下面一行黑底药丸 |
| mascot | Pose | 无 | 落点时右下角探出的小咸鱼 |
| vertical | boolean | false | 竖屏 |

```tsx
const hook = () => ({
  t0: S('h1'),
  t1: E('h4'),
  lines: [
    {at: C('h1', 'a'), text: '绑卡总是*被拒*？'},
    {at: C('h2', 'b'), text: '订阅到一半*卡住*？'},
  ],
  land: {at: C('h4', 'land'), text: '这期*一次*讲清楚', sub: '国内卡也能订 Claude Pro'},
  mascot: 'point' as const,
});
<Hook t={t} {...hook()} />            // sfx: ...hookSfx(hook())
```

常见用错：把整句口播塞进 `text`（要的是 10 字左右的「痛点短句」）；`land.at` 早于最后一句痛点。

### TitleCard 片名字卡

**什么时候用**：钩子之后亮片名。**别用**：章节标题（用 ChapterBreak）。

| prop | 类型 | 默认 | 含义 |
|---|---|---|---|
| title | string | — | 片名，最多两行，`*星号*` 强调 |
| sub | string | 无 | 一句话说这期能得到什么 |
| kicker | string | 无 | 片名上方的小黑标签，如「AI 工具教程 · 第 7 期」 |
| mascot | Pose | 无 | 右侧站立的小咸鱼 |
| char | `{src?, frames?, h?}` | 无 | 换成别的角色图（public 下路径，三帧抖动给 frames） |

```tsx
const tc = () => ({t0: S('t1'), t1: E('t1'), title: '国内卡订 *Claude Pro*', sub: '从注册到付款，一步不落', kicker: 'AI 工具教程', mascot: 'wave' as const});
<TitleCard t={t} {...tc()} />          // sfx: ...titleCardSfx(tc())
```

常见用错：同时给 mascot 和 char（只画 char）。

### Roadmap 本期路线

**什么时候用**：开头 20 秒内说「这期讲几件事」（用户明确要求过开头要讲清本期讲什么）。换章时可以再放一次，用 `focus` 点亮正在讲的那项。
**别用**：超过 5 项。

| prop | 类型 | 默认 | 含义 |
|---|---|---|---|
| title | string | 这期讲几件事 | 标题 |
| items | `{at, text, sub?, icon?}[]` | — | 2–5 项 |
| focus | `{at, i}[]` | [] | 到 at 时点亮第 i 项（从 0 数），其余变淡，带「现在讲」角标 |

```tsx
const road = () => ({t0: S('r1'), t1: E('r2'), items: [
  {at: C('r1', 'reg'), text: '注册账号', sub: '邮箱就够', icon: 'user'},
  {at: C('r1', 'pay'), text: '绑卡付款', icon: 'card'},
  {at: C('r2', 'safe'), text: '防封小技巧', icon: 'shield'},
]});
<Roadmap t={t} {...road()} />          // sfx: ...roadmapSfx(road())
```

### ChapterTag 章节牌 / ChapterBreak 换章过场

**ChapterTag**：整章常驻在左上角。`t0` 设成章节开始（或过场结束），`t1` 设成章节结束。props：`text`、`icon`（或 `n` 显示章号）、`tone`。
**ChapterBreak**：一张大纸推进来盖满画面，大号「01」+ 标题，停一下再推走。props：`t0`、`n`、`title`、`sub?`、`icon?`、`tone?`、`dur?`（缺省 2.1 秒）。推入、推出各 0.35 秒，字随纸一起进出，标题清楚可读的时间约 `dur - 0.6`。**标题要能读 1.2 秒以上，所以 `dur` 不能小于 1.9**（小于会在控制台报警）。它会盖住下面所有东西，过场期间别安排要看的内容。

时间公式（照抄，配合 `film.json` 的 `pacing.chapterGap = 0.9`、`pacing.leadLine = 1.2`）：

```tsx
const brk = () => ({
  t0: chapter('b').start - 0.8,                                 // 上一章结束后 0.1 秒推进来
  dur: chapter('b').first - chapter('b').start + 0.85,          // 第一句开口后 0.05 秒推走；leadLine=1.2 时约 2.05 秒
  n: 2, title: '绑卡付款', sub: '国内卡也行', icon: 'card',
});
const tag = () => ({t0: brk().t0 + brk().dur - 0.2, t1: chapter('c').start, text: '二 · 绑卡付款', n: 2});
<ChapterBreak t={t} {...brk()} />
<ChapterTag t={t} {...tag()} />
// sfx: ...chapterBreakSfx(brk()), ...chapterTagSfx(tag())
```

常见用错：把 `film.json` 的 `leadLine` 调回 0.55，过场只剩 1.4 秒，标题一闪而过读不完；场景的 range 起点没跟着改成 `start - 0.8`，过场前半截不显示。

常见用错：ChapterTag 和别的积木的标题同时在左上角（整屏积木的标题从 y=150 开始，不会撞；自己写的东西别放进左上角 600×130 的区域）。

### CardRow 卡片排

**什么时候用**：2–4 个并列的东西（方案、特点、规矩）。**别用**：有先后顺序的操作步骤（用 StepList）；超过 4 项。

| prop | 类型 | 默认 | 含义 |
|---|---|---|---|
| title | string | 无 | 这一排的标题 |
| items | CardItem[] | — | 2–4 张：`{at, title, desc?, icon? 或 img?, badge?, tone?, mark?: 'ok'\|'no', markAt?}` |
| arrows | boolean | false | 卡之间画箭头（表示先后） |
| shrinkAt | number | 无 | 到这个时刻整排缩小、移到顶上，给下面让位 |

```tsx
const cards = () => ({t0: S('p3'), title: '三种付款方式', items: [
  {at: C('p3', 'a'), title: '国内信用卡', desc: '最省事', icon: 'card', badge: '推荐'},
  {at: C('p3', 'b'), title: '虚拟卡', desc: '成功率高', icon: 'shieldCheck', tone: 'mint' as const, mark: 'ok' as const},
], shrinkAt: C('p4', 'more')});
```

还没念到的卡会先画一个淡淡的虚线占位（从 `t0` 起），所以一张张出现时版面始终对称，不用自己补。

常见用错：`img` 用横长图（卡里是方形裁切）；用 shrinkAt 让位后，下面放的东西要从 y≈480 往下放；卡排的 `t0` 设得太早（占位框会提前好几秒挂在那儿），设成这一屏第一句开口前 0.1 秒就好。

### Versus 左右对比

| prop | 类型 | 默认 | 含义 |
|---|---|---|---|
| kind | 'vs' \| 'before-after' \| 'wrong-right' | 'vs' | vs 蓝对橙、中间 VS；before-after 灰对绿、中间箭头；wrong-right 左错（橙叉）右对（绿勾） |
| left / right | `{at, title, items?: {at?, text}[], icon?, img?}` | — | 两边；每边 ≤4 条要点 |
| verdict | `{at, win: 'left'\|'right', text?}` | 无 | 判定：赢的放大加章，输的变灰 |
| title | string | 无 | 顶部标题 |

```tsx
const vs = () => ({t0: S('v1'), kind: 'wrong-right' as const,
  left: {at: C('v1', 'wrong'), title: '错误做法', items: [{text: '被拒就连着重试'}]},
  right: {at: C('v1', 'right'), title: '正确做法', items: [{text: '先停几个小时'}]},
  verdict: {at: C('v2', 'so'), win: 'right' as const}});
```

常见用错：`wrong-right` 把对的放左边（规定左错右对）。

### StepList 步骤清单

**什么时候用**：操作步骤。念到哪步哪步高亮（橙框），之前的打勾（绿），`doneAt` 时最后一步也打勾。常和右边的 Phone / AppWindow 配：`slot: 'left'`。

| prop | 类型 | 默认 | 含义 |
|---|---|---|---|
| title | string | 无 | 标题 |
| steps | `{at, text, sub?, icon?}[]` | — | 2–6 步 |
| doneAt | number | 无 | 全部完成的时刻 |
| slot | Slot | 'center' | left/right 占半屏 |
| ghosts | boolean | true | 一开始就把空位虚线列出来 |

```tsx
const steps = () => ({t0: S('s1'), slot: 'left' as const, title: '手机上加卡', steps: [
  {at: C('s1', 'pay'), text: '点「付款方式」'},
  {at: C('s2', 'add'), text: '点「添加付款方式」', sub: '会预授权 1 美元'},
], doneAt: E('s2')});
```

### CheckList 核对清单

一张白卡，条目先淡淡列出，到各自 `at` 盖上 ✓（ok 缺省 true）或 ✗（`ok: false`）。props：`title?`、`items: {at, text, ok?, note?}[]`（2–6 条）、`listFirst`（默认 true；false 则到 at 才出现）、`slot`。

```tsx
const chk = () => ({t0: S('k1'), title: '付款前对一遍', items: [
  {at: C('k1', 'a'), text: '卡开通了外币支付'},
  {at: C('k2', 'b'), text: '一小时内反复提交', ok: false, note: '会被风控'},
]});
```

### BigNumber 大数字

一个巨大的数（从 `from` 滚到 `value`）或短词，加一行注解（黄色荧光笔划过）。props：`value: number | string`、`from?`（默认 0）、`decimals?`、`comma?`、`prefix?`（如「¥」）、`unit?`（如「元」「%」）、`label`、`note?`（来源小字）、`labelAt?`、`tone?`、`roll?`（滚动秒数 1.1）、`mascot?`。

```tsx
const big = () => ({t0: C('n1', 'six'), value: 6, unit: '步', label: '从注册到订阅，一共只要这么多'});
```

常见用错：数字没有出处还加 note 冒充数据——数字照实，示例就写「示例」。

### BarChart 对比条和排行

props：`title?`、`rows: {at, name, value, label?, icon?, tone?, note?}[]`（2–6 行）、`max?`（满格值，缺省最大值）、`unit?`、`hi?: {at, i}[]`（高亮第 i 行：黄圈 + 星）、`dimOthers?`（默认 true）。

```tsx
const bars = () => ({t0: S('b1'), title: '同一道题用时', max: 60, rows: [
  {at: C('b1', 'c'), name: 'Claude', value: 32, label: '32 秒', tone: 'coral' as const},
  {at: C('b1', 'g'), name: 'GPT', value: 41, label: '41 秒', tone: 'ink' as const},
], hi: [{at: C('b2', 'win'), i: 0}]});
```

### Table 表格

props：`title?`、`cols: {title, w?, align?}[]`（2–5 列，`w` 是宽度权重）、`rows: {at, cells: string[]}[]`（≤6 行）、`hi?: {at, r, c?}[]`（高亮第 r 行第 c 格；不给 c 就整行）。格子里写 `'✓'` / `'✗'` 会画成绿勾 / 橙叉，`'—'` 是灰色「没有」。

```tsx
const tb = () => ({t0: S('t1'), cols: [{title: '方式'}, {title: '成功率'}, {title: '推荐'}], rows: [
  {at: C('t1', 'a'), cells: ['国内信用卡', '中', '✓']},
  {at: C('t1', 'b'), cells: ['找人代充', '高', '✗']},
], hi: [{at: C('t2', 'hi'), r: 1}]});
```

常见用错：竖屏放 5 列（字会被压到 28px 下限，读不动），竖屏 ≤3 列。

### Flow 流程图

props：`nodes: {id, at, text, sub?, icon?, x?, y?}[]`（row/column ≤5 个，free ≤8 个）、`edges?: {from, to, at?, label?, dashed?}[]`（不给就按顺序连）、`layout?: 'row' | 'column' | 'free'`（竖屏缺省 column）、`path?: {at, id}[]`（走到哪：当前橙色、走过的绿色带勾，路过的箭头上跑一个小点）、`title?`。free 布局的 x/y 是节点中心的舞台坐标，自己保证在安全区里（横屏 x 260–1660、y 230–840）。

```tsx
const flow = () => ({t0: S('f1'), nodes: [
  {id: 'a', at: C('f1', 'a'), text: '建档', icon: 'layers'},
  {id: 'b', at: C('f1', 'b'), text: '切换', icon: 'swap'},
  {id: 'c', at: C('f1', 'c'), text: '登录', icon: 'logIn'},
```

### Timeline 时间线

props：`points: {at, date, text, sub?, tone?}[]`（3–6 个）、`now?: {at, i}`（高亮「现在」那一个）、`title?`。横屏卡片上下交错，竖屏轴在左。

### ImageShow 图片展示

一张图放进白相框（带题注、左上标签），可以推近某一点、圈出一块并标字。

| prop | 类型 | 默认 | 含义 |
|---|---|---|---|
| src | string | — | public 下路径；或 `render: (w, h) => ReactNode` 用代码画 |
| ratio | number | 16/9 | 图的宽/高，**必须给对**，否则变形或裁切 |
| caption | string | 无 | 相框下方题注（自动加「」） |
| tag | string | 无 | 左上标签，如「群友截图」 |
| zoom | `{at, x, y, s}[]` | [] | 到 at 起 0.8 秒推到图上 (x,y)（0..1），放大 s 倍；推回原样写 `{x: .5, y: .5, s: 1}` |
| circles | `{at, t1?, x, y, w, h, label?}[]` | [] | 圈出一块（0..1 坐标，按原图量） |
| slot | Slot | center | 半屏放 |

```tsx
const img = () => ({t0: S('i1'), src: 'shots/settings.png', ratio: 1920 / 1080, tag: '示意截图', caption: '设置 → 订阅',
  zoom: [{at: C('i1', 'zoom'), x: 0.8, y: 0.38, s: 2.2}],
  circles: [{at: C('i1', 'here'), x: 0.73, y: 0.33, w: 0.18, h: 0.09, label: '点这里升级'}]});
```

常见用错：circles 的坐标按推近后的画面量（要按原图量）；圈的东西推近后不在画面里。

### ShotWall 截图墙 / TextShot 文字截图

ShotWall：`shots: {at, ratio, src? 或 render?, label?, labelTone?}[]`（≤6 张，位置和角度按张数预排好，不用填坐标）、`title?`、`badge?`（标题旁小章，如「真实原话」）。
TextShot：把原话排成截图样，给 `render` 用：`render: (w, h) => <TextShot w={w} h={h} kind="chat" lines={[{text: '出狱了！！！'}]} />`。`kind: 'comment'` 是评论区样（带点赞数）。**只放真实原话**，去掉昵称和头像（缺省显示「群友」「观众」）。

### ChatBox 聊天窗

| prop | 类型 | 默认 | 含义 |
|---|---|---|---|
| skin | 'claude' \| 'chatgpt' \| 'qq' \| 'plain' | 'claude' | 配色像谁（不画真实商标） |
| title | string | 新对话 | 标题栏 |
| msgs | ChatMsg[] | — | 见下 |
| aiName | string | 按皮肤 | 对方名字（qq / plain 显示） |
| slot | Slot | center | left/right 半屏 |

消息种类：
- `{at, from: 'me', text, typeFrom?}`：typeFrom 起在输入框里逐字打，at 时发出。
- `{at, from: 'ai', text, thinkFrom?, stream?, name?}`：thinkFrom 起显示「正在输入」三个点；at 起逐字流出（每秒 30 字；`stream: false` 整段出）。
- `{at, from: 'tool', text, done?, doneText?}`：工具调用卡，转圈到 done 打勾。
- `{at, from: 'file', name, size?, mine?}`：文件卡。
- `{at, from: 'note', text}`：居中灰字。

```tsx
const chat = () => ({t0: S('c1'), skin: 'claude' as const, title: '订阅失败怎么办', msgs: [
  {at: C('c1', 'send'), from: 'me' as const, text: '帮我写排查步骤', typeFrom: S('c1') + 0.3},
  {at: C('c2', 'reply'), from: 'ai' as const, thinkFrom: C('c1', 'send') + 0.3, text: '按这个顺序查：一，……'},
]});
```

常见用错：一条消息塞一大段（ai 最多 8 行、me 最多 6 行，超了截断）；消息多了会自动往上滚，不用自己删旧的。

### Terminal 终端窗

props：`lines: ({at, cmd, cps?} | {at, out, tone?})[]`、`shell?: 'powershell' | 'bash' | 'cmd'`、`cwd?`、`title?`、`slot?`、`h?`（窗口高度，输出行少时给小一点，缺省占满安全区）。命令每秒敲 22 字（cps 改），长行自动折行，满了自动上滚。tone：ok 绿、warn 黄、err 红、mute 灰。

```tsx
const term = () => ({t0: S('n1'), lines: [
  {at: C('n1', 'type'), cmd: 'npm install -g @anthropic-ai/claude-code'},

```

### AppWindow 通用软件窗口（仅横屏）

演示任何电脑软件的操作：标题栏、可选侧栏，内容区从上往下自动排控件；配光标和说明牌。

| prop | 类型 | 含义 |
|---|---|---|
| title / icon / iconTone | | 标题栏 |
| sidebar | `{items: {text, icon?}[], active?, activeAt?: {at, i}[]}` | 侧栏；activeAt 让选中项随时间变 |
| body | Widget[] | 控件，见下 |
| dialog | `{at, t1?, title, text?, buttons, press?, pressAt?, danger?}` | 弹窗，最后一个按钮是主按钮 |
| toast | `{at, t1?, text, tone?}` | 顶部提示条 |
| cursor | Way[] | 光标脚本 |
| slot | Slot | 半屏放 |

控件（Widget），都可以带 `id` 好让光标找到它：
- `{kind: 'title', text}`、`{kind: 'text', text}`
- `{kind: 'input', label?, placeholder?, value?, typeFrom?, typeTo?, secret?}`（typeFrom 起逐字打出 value）
- `{kind: 'button', text, tone?: 'primary'|'plain'|'danger', pressAt?, icon?}`
- `{kind: 'toggle', label, sub?, on?, flipAt?}`
- `{kind: 'select', label?, value, options?, openAt?, pickAt?, pick?}`（展开、选第 pick 项）
- `{kind: 'notice', text, tone?: 'info'|'ok'|'warn'|'err'}`
- `{kind: 'list', items: {text, sub?, icon?}[], hiAt?: {at, i}[]}`
- `{kind: 'row', children: Widget[]}`（一行并排，通常放两个按钮）、`{kind: 'space', h}`

**光标怎么对准**：`appLayout(props)` 返回每个带 id 的控件的舞台坐标；侧栏第 i 项是 `'side.i'`，弹窗第 i 个按钮是 `'dialog.i'`。`aim(布局, 'id', 时刻, {dx?, dy?})` 生成一个点击落点。缺省不点正中心，而是点在控件右侧约 1/3、略偏下的地方：光标图标从落点往右下画，这样按钮上的字留在光标左上方，不会被手盖住。要点别处（比如开关的拨钮）才自己给 `dx / dy`（相对控件中心）。

**说明牌放哪（`PointNote` 的 `dir`）**：牌子放在目标的**空白一侧**，别盖住目标和它旁边的字。口诀：**目标在上半屏朝下放，在下半屏朝上放；目标在一行字的末尾朝右放，在行首朝左放；目标旁边有字的那一侧不放。** 锚点 `x, y` 取目标的边沿（朝上放就取目标上边沿 `y`，朝右放就取右边沿 `x`），不要取中心；牌子默认离锚点 100px，够空出目标本身。放好后抽一帧看：牌子、光标都不能压住要强调的那几个字。

```tsx
const win = (): AppWindowProps => ({t0: S('w1'), title: 'Claude 设置', icon: 'settings',
  sidebar: {items: [{text: '通用'}, {text: '订阅', icon: 'card'}], activeAt: [{at: C('w1', 'sub'), i: 1}]},
  body: [
    {kind: 'title', text: '订阅与付款'},
    {kind: 'input', id: 'card', label: '卡号', value: '6222 0000 0000 0000', typeFrom: C('w2', 'type')},
    {kind: 'button', id: 'pay', text: '确认订阅', pressAt: C('w3', 'ok')},
  ],
  toast: {at: C('w3', 'ok') + 0.3, text: '订阅成功'}});
const L = () => appLayout(win());
const ways = () => [{at: S('w1'), x: 1500, y: 860}, aim(L(), 'side.1', C('w1', 'sub')), aim(L(), 'card', C('w2', 'type') - 0.1), aim(L(), 'pay', C('w3', 'ok'))];
<AppWindow t={t} {...win()} cursor={ways()} />
<PointNote t={t} at={C('w3', 'ok') - 0.4} x={L().pay.cx} y={L().pay.y} dir="up" text="点 *确认订阅*" num={3} />
<DemoMark />
// sfx: ...appWindowSfx({...win(), cursor: ways()})   ← 光标点击声也在里面
```

常见用错：光标时刻和控件的 pressAt / typeFrom / openAt 对不上（让它们用同一个 C(...)）；控件太多超出窗口（控制台会警告，删掉一些或拆两屏）；界面用代码模拟时忘了放 `<DemoMark />`（角落「示意画面」）。

## 版式通则

1. **安全区**。横屏 1920×1080：内容在 x 110–1810、y 150–915 之间；y>940 是字幕条，绝不放东西；左上角（x<700、y<130）是章节牌。竖屏 1080×1920：内容在 x 80–1000、y 240–1480；上 220 和下 420 是平台界面和字幕。整屏积木默认都在安全区内，自己加小件时也守这个框。
2. **字号档位**（横屏 px）：巨字 150–280（大数字、开场落点）；整屏大标题 96–132（得意黑）；区块标题 64–76（得意黑）；卡片标题 40–46（黑体 900）；正文 30–40，**下限 28**；说明小字 26–28，**下限 24**。手机上看，比这更小就读不动了。
3. **一屏最多放多少**：一块整屏积木 + 章节牌 + 至多两个小件（盖章、说明牌、吉祥物）。卡片 ≤4 张，步骤 ≤6 步，表格 ≤5 列 6 行，条形图 ≤6 行，流程节点 ≤5 个，截图 ≤6 张。超了就拆成两屏，别缩。
4. **颜色含义**：珊瑚橙 coral＝强调、警告、错、「现在」；薄荷绿 mint＝对、完成、通过；黄 sun＝荧光笔、高亮圈；蓝 sky＝中性信息、按钮、链接；墨蓝 ink＝文字、描边、深色标签；红只用在 WarnCard danger。不要引入新颜色。
5. **动画时长惯例**：元素在念到它的那一刻弹出（弹簧约 0.3 秒到位）；同一屏条目之间至少隔 0.3 秒；退场统一 0.3 秒淡出；推近 0.8 秒；整屏换版之间留 0.3 秒以上空隙或用 ChapterBreak。别让东西在没念到时就先出来。
6. **一切都是 `t` 的函数**：不用 `Math.random`、`Date`、`useCurrentFrame`、Remotion 的 `interpolate` / `spring`。要动画就用 `lib/anim.ts` 的 `prog`、`tween`、`spring`、`appear` 和 blocks 的 `pop`、`vis`。
7. **不要自己从零写的东西**：卡片、标题、标签、表格、列表、聊天窗、终端、软件窗口、手机框、箭头、盖章、集中线、片尾。要的版式积木里没有，先想能不能用两块积木拼（比如 StepList slot=left + Phone），实在没有再写，而且写的时候也用 FitText 放字、用 Card/Tag/IconBox 做外观。
8. **模拟界面**：教程里的软件界面用 AppWindow / Phone / ChatBox 加假数据画，角落放 `<DemoMark />`（只写「示意画面」）。真实截图用 ImageShow / ShotWall。
9. **画面禁忌**：不用红色圆盘配放射光芒；爆发感用 SpeedLines 和 Burst。

## 一个完整场景怎么写

照抄模板示范片：`src/scenes/Hook.tsx`（开场钩子 + 本期路线）、`Script.tsx`（换章过场 + 章节牌 + 卡片排 + 给气泡让位）、`Sync.tsx`（流程图 + 盖章）、`Run.tsx`（终端窗 + 说明牌 + 核对清单 + 示意画面）、`End.tsx`（回顾 + 片尾卡）。竖屏短版看 `src/short/Short.tsx`。每个文件的注释就是教程，按这个骨架写：

```tsx
import React from 'react';
import type {Ev} from '../kit/sfx';
import {C, E, S, chapter} from '../lib/time';          // 竖屏短版改成 from './timeShort'
import {ChapterTag, CardRow, cardRowSfx, chapterTagSfx, vis} from '../blocks';
import type {Scene} from './common';
import {edge} from './common';

// 1. range：这一幕从几秒画到几秒。一律用时间表，不写数字
const range = () => [chapter('a').start - 0.5, chapter('b').start] as const;

// 2. 每块积木一个 props 函数：组件和音效共用，时间只写一遍
const tag = () => ({t0: chapter('a').first - 0.2, t1: chapter('b').start, text: '一 · 稿子带标记', n: 1});
const cards = () => ({t0: S('a1') - 0.1, items: [{at: C('a1', 'line'), title: '口播句', icon: 'chat'}]});

// 3. 组件：最外层用 edge() 做整幕淡入淡出；后写的画在上面（换章过场放最后）
const SceneA: React.FC<{t: number}> = ({t}) => {
  const [a, b] = range();
  return (
    <div style={{position: 'absolute', inset: 0, opacity: edge(t, a, b)}}>
      <ChapterTag t={t} {...tag()} />
      <CardRow t={t} {...cards()} />
    </div>
  );
};

// 4. sfx：把每块积木的音效函数展开
const sfx = (): Ev[] => [...chapterTagSfx(tag()), ...cardRowSfx(cards())];

// 5. 导出，并在 scenes/index.ts 的 SCENES 里登记（顺序就是图层顺序）
export const SceneAScene: Scene = {id: 'a', range, C: SceneA, sfx /*, demo */};
```

要点：

- **range**：起点一般取 `chapter('x').start - 0.8`（换章过场从这里推进来），终点取下一章的 `chapter('y').start`；开场那一幕的终点是 `sting('intro').start + 0.2`，收尾那一幕的终点是 `sting('outro').start + 0.15`（片头片尾视频盖在最上层，多画一点避免露底）。
- **edge(t, a, b)**：整幕开头 0.35 秒淡入、结尾 0.35 秒淡出。每一幕最外层都包一层。
- **时间**：`chapter('x').start` 章节开始，`chapter('x').first` 这章第一句开口；`S('句')` 句子开始、`E('句')` 句子结束、`C('句','标记')` 念到标记的瞬间。气泡用 `bubble('q1').start`，片头片尾用 `sting('intro')`。
- **为什么常常提前 0.05 秒**（`t0: C(...) - 0.05`）：积木的弹出动画开头 0.05 秒几乎看不见，提前一点，眼睛看到的出现时刻才和声音对上。
- **元素什么时候退场**：一屏换下一屏时，前一块的 `t1` 设成「下一块出现前 0.1–0.15 秒」（如 `t1: S('c3') - 0.15`），退场淡出 0.3 秒，和下一块的弹出刚好交接，不会两块叠在一起；想「念完这句就收」就用 `t1: E('句')`；一直留到这幕结束就不写 t1，交给 edge 淡出。
- **换章过场**：`ChapterBreak` 的 `t0: chapter('x').start - 0.8`、`dur: chapter('x').first - chapter('x').start + 0.85`，第一句开口时它刚好推走；章节牌 `t0` 设在过场推走前 0.2 秒。**标题要能读 1.2 秒以上**：这要求 `film.json` 的 `pacing.leadLine` 不低于 1.05（模板是 1.2）、`chapterGap` 不低于 0.8（模板是 0.9）。
- **气泡**：无声气泡由 `Film.tsx` 统一画在左下角（`q2` 画成大号居中），场景只负责让位：卡片排用 `shrinkAt: bubble('q1').start - 0.6` 缩到顶上，或者让积木在气泡前退场。
- **demo**：画了模拟界面（终端、软件窗口、手机、聊天窗）的那一幕，给 Scene 加 `demo: (t) => vis(t, 窗口的t0, 窗口的t1)`，`Film.tsx` 会在角落标「示意画面」。
- **标记全被用上**：每个 `{标记}` 都应该有画面在用，`.ilm.cmd lint` 会列出没人用的标记和引用错的标记；场景注释里也别写不存在的 `C('x','y')`，lint 会把注释里的引用一起查。
- **改完的验收顺序**：`.ilm.cmd lint` → `.ilm.cmd voice zh` → `.ilm.cmd probe zh --round 名字`（错误清零）→ `.ilm.cmd review zh --round 名字`（逐张看 `review\名字\` 的原图）→ `.ilm.cmd all zh`。
